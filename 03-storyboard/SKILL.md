# 分镜表制作标准（Storyboard Table）

> **链路入口**：本 skill 是全链路第 2 环（分镜层），全链路图 + 交接表 + 路由表见 `01-pipeline-orchestrator`。字段契约（JSON 交换格式）见 `01-pipeline-orchestrator/references/api-contracts.md`。
> 版本：v1.0　｜　生效日期：2026-10-27
> 适用范围：AI 短剧、漫剧、品牌 TVC、定制短片、宣传片——凡是要把剧本拆成镜头清单的活，全部按本标准。

---

## 〇、先搞清楚：分镜表 ≠ 提示词

这是最容易搞混的地方，先说死。

| | 分镜表 | 提示词（17 段式） |
|---|---|---|
| 是什么 | 全片的**拍摄计划表** | 单个镜头的**生成指令** |
| 给谁看 | 人（导演、剪辑、AI 操作员） | AI 模型 |
| 颗粒度 | 一整个片子，几十个镜头 | 一条提示词，1 个到几个镜头 |
| 有没有焦段 | **不写焦段**，只写景别 | 必写焦段 + 光圈 f 值 |
| 产出顺序 | **先做分镜表** | 拿分镜表逐条转提示词 |

**做分镜表时不要写焦段、不要写光圈、不要写反向提示词。** 这些是后面做提示词时才配的。

**标准工作流（含上下游 skill）：**

```
ip-script-pipeline（剧本层）
└─ 产出：剧本定稿 + 人物定妆单 + 简介单
        ↓
storyboard-table（本文件 · 分镜层）
└─ 消费：剧本（拆情节）+ 人物定妆单（引用名字）
└─ 产出：分镜表（10 列）+ 资产清单表（分镜后统计）
        ↓
character-design-sheet（资产层）
└─ 消费：分镜表「备注」列的资产统计 → asset-tiering 判级
└─ 消费：分镜表「人物」列 → 从定妆单取外貌
└─ 产出：定妆照/多视图/三视图/色卡 + 提示词
        ↓
生成层（外部工具）
└─ 消费：分镜表 + 资产图 + 提示词
└─ 产出：图片/视频
```

**本文件只管「分镜表」这一层**：往上消费剧本，往下给出资产统计和字段映射，不越界到剧本层或资产层。

## 一、表头：十列，一列不能少、不能多

```
分镜号 | 镜头号 | 建议时长 | 画面描述 | 人物 | 台词 | 运镜 | 构图 | 景别 | 备注
```

**固定这个顺序，不要自己加减列。**

### 各列作用一览

| 列 | 作用 | 宽度占比 |
|---|---|---|
| **分镜号** | 一场戏/一个情节单元 | 最窄 |
| **镜头号** | 该分镜内第几个镜头 | 最窄 |
| **建议时长** | 单镜秒数，纯数字不带单位 | 最窄 |
| **画面描述** | 时间地点 + 发生什么 | **最宽** |
| **人物** | 本镜出场谁 | 中等 |
| **台词** | 谁说什么，带情绪标注 | **次宽** |
| **运镜** | 摄像机怎么动 | 中等偏窄 |
| **构图** | 画面怎么摆 | 中等偏窄 |
| **景别** | 拍多大范围 | 窄 |
| **备注** | 本镜需要的资产 | 中等 |

## 二、时长怎么判断（核心）

### 2.1 先记死这三个数

```
单镜最短    3 秒
单镜常规    5 秒   ← 44 个镜头里出现最多
单镜最长    10 秒
```

**绝大多数镜头写 5。** 不知道写多少的时候，写 5 就对了。

> **样本说明（重要）**：上面三个数来自汽车 TVC 的统计（《逆境》44 镜 / 221 秒，平均 5 秒/镜）。**默认值按片子类型调**：
>
> - **汽车 TVC / 品牌宣传片**（氛围为主）：默认 5 秒，单镜上限 10 秒——**本表默认值直接适用**
> - **短剧**（对话密集）：默认 3-4 秒，单镜上限 7 秒——对话多、节奏快，5 秒偏长
> - **漫剧**（动作密集）：默认 2-3 秒，单镜上限 6 秒——动作切得快，长镜会拖
> - **氛围宣传片**（空镜多）：默认 6-8 秒，单镜上限 12 秒——要给观众看清环境
>
> **规则框架不变，默认值按类型调。** 做非 TVC 类型时，先改这三个数，再套后面的时长判断规则（2.2 的四种情况仍然适用，只是「基准秒数」变了）。

### 2.2 四种情况对应四种时长

**① 空镜 / 环境镜头 → 5-7 秒**

```
冰川近景，冰体崩开一个大口子 → 7 秒
帐篷内景，灯影摇晃           → 4 秒
```

不需要动作完成，观众要看清楚「这是什么」，所以给够时间。

**② 单人说话 → 看字数**

```
字数 ÷ 4 = 秒数（正常语速）
字数 ÷ 3 = 秒数（慢速、情绪戏）
```

```
「哥！路没了！」        6 字 → 2 秒，但情绪爆发要留反应时间 → 写 4
「人下来，上车」        5 字 → 1.5 秒 → 写 5（这话要停顿、要有份量）
```

**台词镜头一律加 1-2 秒余量**，不然口型对不上。

**③ 多人对话 → 5 秒起**

一个 5 秒镜头里塞两三轮对话是常态：

```
梁小：……咱这连个大屏都没有／梁大（目视前方，平静）：它不挑路      → 5 秒
邓总（举杯）：这才叫生活／琳琳（笑）：亲爱的你这车真是绝了／邓总（指雪山）：明天一早……  → 5 秒
```

**多人对话用「／」分隔每人台词，一个镜头可以承载 2-3 句。**

**④ 完整动作 → 必须走完全程**

```
起步/抬手/转身      → 3-4 秒
走过来（3 米）      → 5 秒
跑过来（10 米）     → 6-7 秒
两车交错            → 10 秒（错车要走到过完）
```

**动作没走完，观众会觉得画面被剪断了。**

### 2.3 什么时候用一个长镜头（8-10 秒不切）

**条件：一个镜头里同时有运镜变化 + 台词，切开就散了。**

实例（《逆境》分镜 1，8 秒）：

```
画面：傍晚雪域峡谷公路，两台车正在行驶
台词：画外音（前车）：……要不我们今晚就在这里露营吧！／小梁：好嘞，邓总！
运镜：航拍大远景持续下降，落到能看清整个车队的中景（全程不换机位）
景别：大远景→中景
```

**8 秒干完三件事：交代环境 + 交代人物关系 + 台词完成。切开了反而碎。**

实例（分镜 3，10 秒）：

```
画面：弯道处对面驶来破旧救援皮卡，两车交错而过
运镜：错车慢镜，两车交错而过（全程不换机位）
景别：中景→近景
```

**错车这个动作本身就要 8 秒以上，切开没意义。**

## 三、一个分镜放几个镜头

### 3.1 结论：1-3 个，最多 3 个

**这是统计出来的，不是拍脑袋：** 18 个分镜、44 个镜头、221 秒——

```
1 镜的分镜    5 个（占比 28%）
2 镜的分镜    4 个（占比 22%）
3 镜的分镜    9 个（占比 50%）
4 镜以上      0 个
```

### 3.2 为什么最多 3 个

**分镜 = 一个情节单元，超过 3 个镜头就说明里面装了两件事，该拆成分镜了。**

```
✅ 分镜 6（3 镜）：老炮警告 → 众人不以为意 → 梁大回头看一眼
   → 一件事：警告被忽视，但有人听进去了

❌ 硬塞成一镜 6 个：加上「老炮开车走人」+「众人继续喝酒」+「天黑了」
   → 这是三件事，必须拆
```

### 3.3 什么时候用 1 个、2 个、3 个

**用 1 个镜头的三种情况：**

```
① 长镜头不切（错车、坠落、爆炸、一镜到底的连续动作）
② 空镜（冰川崩裂、夜空、车灯特写）
③ 尾板 / 字幕镜头
```

**用 2 个镜头的两种情况：**

```
① 一远一近（环境→人物）
② 一前一后（发生→反应）
```

**用 3 个镜头的两种情况：**

```
① 标准三镜法：环境/全景 → 人物中景 → 情绪近景
② 递进三镜法：中景 → 中近景 → 特写（往人物内心推）
```

### 3.4 一个分镜的总时长控制在 5-15 秒

```
1 镜：5-10 秒
2 镜：10-12 秒
3 镜：12-15 秒
```

**为什么上限 15 秒：** 一段情节超过 15 秒，观众注意力会散；而且图生视频单次生成一般 5-10 秒，越长越难保持一致性。

## 四、分镜号与镜头号的编码规则

```
分镜号：1、2、3……18        顺序编号，不跳号
镜头号：每个分镜内从 1 重来  1、2、3
```

**多个镜头共用同一个分镜号，靠镜头号区分：**

```
1 | 1 | 8  | ...   ← 分镜1，只有1个镜头
2 | 1 | 4  | ...   ← 分镜2，第1镜
2 | 2 | 5  | ...   ← 分镜2，第2镜
2 | 3 | 3  | ...   ← 分镜2，第3镜
3 | 1 | 10 | ...   ← 分镜3，只有1个镜头
```

## 五、各列怎么写（附实例）

### 5.1 画面描述

**公式：时间 + 地点 + 谁/什么 + 在干什么（只写看得见的）**

```
✅ 傍晚，雪域峡谷公路，数千米雪山夹峙的峡谷中一条泥泞土石路蜿蜒入山；两台车正在行驶
✅ 公路变窄，坑洼、碎石、暗冰；贴地拍车轮——EVX-9
✅ 切到小梁正脸，置于左三分线
✅ 两车停在巨大雪山脚下的开阔地，营地紧邻极宽阔结冰湖面
❌ 梁大心里很难受，他想起父亲 （心理活动，AI 拍不出来）
❌ 气氛压抑，充满宿命感          （形容词，不可执行）
```

**规则：**
- 时间地点必须有（`傍晚` / `入夜` / `清晨` / `晨光刺破天际`）
- 动作必须是**外部看得见**的，不写心理活动
- 需要切换机位时写明（`切进车内中近景` / `切到小梁正脸`）
- 两句以内，用分号「；」连接，不用句号

### 5.2 人物

```
无                    ← 空镜、纯环境
梁大                   ← 单人在场
梁大、梁小              ← 多人，用顿号
众人 / 人群（多人）      ← 群演，看不清具体人
老炮（车内）            ← 需要说明位置时加括号
邓总、琳琳（车内）+梁小、梁大
```

**只写名字，不写长相、不写服装。** 长相服装在定妆照里解决。

**长相的唯一来源**：`ip-script-pipeline` 阶段 C5 产出的「人物定妆单」（15 字段，见 `make-spec.md`）——姓名 / 身份 / 年龄 / 性别 / 身高体型 / 脸型五官 / 发型发色 / 皮肤质感 / 服装造型 / 性格关键词 / 行为习惯 / 说话方式 / 人物关系 / 情绪基调 / 参考图。**本表只引用名字，转提示词时从定妆单取外貌描述，不在本表重复写。**

### 5.3 台词

**四种写法，对照使用：**

```
① 有台词 + 情绪标注
梁大（暴喝）：走！全部都走！
邓总（猛拍方向盘，慌张）：怎么不动了？怎么不动了！
梁小（低声，认真）：怎么样，关键时候还是我们老车厉害吧
琳琳（笑）：亲爱的你这车真是绝了

② 多人对话用「／」分隔
梁小：……咱这连个大屏都没有／梁大（目视前方，平静）：它不挑路
邓总（举杯）：这才叫生活／琳琳（笑）：亲爱的你这车真是绝了／邓总（指雪山）：明天一早……

③ 画外音
画外音（小梁）：快来看，这湖面都结冰了
梁小（画外音）：哥，你看人家那车，自动驾驶、空气悬挂……
画外（几人在说笑声）
画外音：微信收到语音（前面是个低洼处……）

④ 无台词 —— 必须明写这四个字
本镜无台词
```

**⛔ 铁规矩：没有台词的镜头，必须写「本镜无台词」，不许留空。**
留空会导致后面转提示词时判断不了，AI 会自己编台词。

**特殊情况：**
```
尾板字幕：有些路，只有它能带你走。——兰德酷路泽
```
字幕、旁白卡写在台词列，标明「尾板字幕」。

### 5.4 运镜

**写主运镜 + 起止状态。一条镜头只写一种主运镜。**

常用词（直接抄）：

```
固定机位
缓慢推近 / 缓慢拉远
缓推+定切
贴地跟拍 / 贴冰跟拍
手持跟拍 / 手持晃动 / 手持+快切
航拍跟拍 / 航拍俯视 / 航拍缓推 / 缓慢升降
缓慢横移 / 缓慢上升
错车慢镜 / 慢镜
多镜快切
上扬后拉
固定+切换
固定/缓推
低角度仰拍 / 高角度俯拍
微距特写 / 浅景深聚焦
长焦拉伸 / 长焦压缩
航拍大远景 / 全景俯视
慢镜头 / 高速快门定格
双重曝光 / 虚实交织
```

**需要写清起止时加括号说明：**

```
航拍大远景持续下降，落到能看清整个车队的中景（全程不换机位）
```

**⛔ 不写「电影感运镜」「高级运镜」这类虚词。**

### 5.5 构图

**短词，2-6 个字，写画面怎么摆。**

```
对角线纵深
低机位平行
左三分线
双人侧拍
过肩/正反打
背影+远景
低角度仰拍
交替构图
帐篷内景
空镜组
大景深
广角大远景
大特写车灯
双车队列
两车交错
侧逆光人像
中近景平视
```

### 5.6 景别

**只写景别，不写焦段、不写光圈。**

```
单景别：大远景 / 远景 / 全景 / 大全景 / 中景 / 中近景 / 近景 / 特写
带运镜变化：大远景→中景 / 中景→近景 / 中景→远景
两镜合并写法（快切组）：中景/特写 / 特写/远景
特殊机位：仰拍全景
```

**为什么景别列不写焦段：**
分镜表是给人看的工作清单，焦段是转提示词时才配的。分镜表阶段先定「拍多大、要不要推」，焦段在写 17 段式提示词时，按景别对应关系去配（近景配 85mm、全景配 24mm……）。

### 5.7 备注

**写本镜需要的资产，让人知道要去生成什么。**

```
空镜
空镜；场景资产
空镜；场景资产：冰湖、冰川
场景资产：冰川
场景资产：营地/冰湖/冰湖
人物资产：梁大、梁小
人物资产：四人
人物群像
有车资产（陆巡+EVX-9）
有车资产（陆巡+EVX-9）；道具：皮卡
人物资产：老炮；道具：皮卡
人物资产：邓总、琳琳、梁小；场景资产：营地/冰湖/冰川
```

**格式：`类型 + 冒号 + 具体名字`，多个用分号分隔。**

类型只有四种：
```
人物资产
场景资产
道具 / 车资产
空镜（不需要人物出场）
```

**备注列的资产统计，是下游判级的精确数据源**：分镜表定稿后，统计每个角色在本表中的「出场镜头数 + 特写镜头数（景别=近景/特写的镜头）+ 累计时长」，这三项直接喂给 `character-design-sheet` 的 `asset-tiering.md` 判级——镜头多 + 特写多 + 时长长 → L0/L1；镜头少 + 无特写 + 时长短 → L2/L3。**比从剧本数台词更准**（剧本数台词数 ≠ 镜头数，分镜表的镜头数才是真实的镜头权重）。

## 五点四、分镜后产出资产清单（本 skill 的第二个产出）

> 分镜表定稿，镜头数据都在手上——顺手统计出「资产清单表」。这是本 skill 的第二个产出，也是下游 `character-design-sheet` 判级的精确依据。

**产出时机**：分镜表定稿后，机械统计，**所有字段一次填满**（因为镜头数据都有了）。

**四张子表（字段严格按 `make-spec.md` 第 3 节，一个不改）**：

| 子表 | 怎么从分镜表数 |
|---|---|
| **3.1 人物清单** | 「出场镜头数」= 分镜表「人物」列出现该角色名字的镜头数；「出场场次/镜头号」= 该角色出现的所有「分镜号-镜头号」列表；「出场累计时长」= 这些镜头的「建议时长」之和 |
| **3.2 场景清单** | 「出场镜头号」= 分镜表「备注」列出现该场景编号的镜头；「出现次数」= 镜头号列表的长度 |
| **3.3 道具清单** | 同上，按「备注」列的道具编号统计 |
| **3.4 声音资产** | 按「人物清单」里有台词的角色，一角色一声音编号（V01/V02…） |

**汇总与命名**：按 3.5 全片资产汇总填数量/完成率；按 3.6 命名规则给每个资产定文件名（`P01_梁大_v1.png` 这种）。

**交给下游**：资产清单表 → `character-design-sheet` 的 `asset-tiering.md` 判级（镜头多+特写多+时长长 → L0/L1；少 → L2/L3）。

**为什么由本 skill 产出**：资产清单的核心字段是「镜头数/特写数/时长」，这些数据**只有分镜表才有**。剧本层数不出镜头，硬做就是估；分镜表做完再统计，是精确的。

**不重复描述资产**：资产清单只写编号 + 统计数字，**不写长相/服装/材质**——那些在人物定妆单和 `character-design-sheet` 的产出里。避免两处描述打架。

**额外产出：场景状态文件（`EPxxx_scene_states.jsonl`）**：分镜表涉及 S0/S1 场景时，除资产清单表外，还要统计产出 `EPxxx_scene_states.jsonl`（每行一个 `SceneState`，字段见 `api-contracts.md` 的 SceneState 对象）。分镜表「备注」列的状态码写法统一为 `SC-01@SS2`（叙事状态，SS0–SS5），供脚本生成 SceneState——**绝不写 `SC-01@S2`**（那是重要度编号，与状态码是两套）。

## 五点五、分镜表 → 提示词的字段映射

> 分镜表是「拍摄计划」，提示词是「生成指令」。分镜表定稿后，逐镜转提示词时按下表取字段——**不重复写分镜表已有的，不漏掉分镜表已定的**。

| 分镜表列 | 转到提示词的哪一段 | 转换规则 |
|---|---|---|
| **景别** | 第 1 段「图种/镜头类型」 | 大远景→`extreme wide shot`，远景→`wide shot`，全景→`full shot`，中景→`medium shot`，中近景→`medium close-up`，近景→`close-up`，特写→`extreme close-up` |
| **画面描述** | 第 2 段「场景/动作」 | 只转「看得见的」——时间地点 + 外部动作；心理活动不转（分镜表里本就不该有） |
| **人物** | 第 3 段「人物/妆造」 | **从人物定妆单取外貌，不在提示词里重复描述**；分镜表只给名字，外貌在定妆单 |
| **台词** | **不转进提示词** | 台词是后期配音/字幕，不是画面生成指令。转提示词时直接跳过这列 |
| **运镜** | 镜头语言参数 | 固定机位→`static shot`，缓慢推近→`slow push in`，手持→`handheld`，航拍→`aerial shot`，错车慢镜→`slow motion` |
| **构图** | 构图描述 | 左三分线→`left third composition`，低机位→`low angle`，过肩→`over-the-shoulder`，对角线→`diagonal composition` |
| **景别→焦段对应** | 第 1 段补焦段 | **分镜表不写焦段，转提示词时按景别配**：大远景/远景→24mm，全景→35mm，中景→50mm，中近景/近景→85mm，特写→100mm+ |
| **备注** | 参考图入口 + 资产编号 | 人物资产→用定妆照做参考图；场景资产→用场景设定图做参考图；道具/车资产→用道具设定图做参考图 |

**转换顺序**：先取景别定「镜头类型 + 焦段」→ 再取画面描述 + 人物（从定妆单展开）定「场景 + 动作」→ 再取运镜 + 构图定「镜头语言」→ 最后取备注挂参考图。**台词列直接跳过。**

**一句话**：分镜表定「拍什么、怎么拍」，提示词定「生成指令」——**两者不重复，也不遗漏**：分镜表有的（景别/运镜/构图）转成提示词参数，分镜表没有的（焦段/光圈/反向词）由提示词补上，分镜表里不写的（长相/服装）从定妆单取。

## 六、七步工作流

### 第 1 步：拆情节

把剧本按「一件事」切开，**每件事 = 一个分镜**。

判断标准：
```
一件事 = 目标 → 阻碍 → 结果，能在 5-15 秒内讲完
```

例（《逆境》前 6 个分镜）：
```
分镜1  车队进山（交代）
分镜2  车内聊车（人物关系）
分镜3  遇到老炮（引入）
分镜4  营地扎营（场景转移）
分镜5  砸冰（埋雷）
分镜6  老炮警告（冲突）
```

### 第 2 步：给每个分镜配 1-3 个镜头

```
长镜头不切 / 空镜 / 尾板        → 1 镜
一远一近 / 一前一后            → 2 镜
三镜法 / 递进法                → 3 镜
```

### 第 3 步：定景别，保证递进

**同一个分镜里，景别要有变化或递进，不许原地不动。**

```
✅ 中景 → 中近景 → 特写        （往内推，情绪加深）
✅ 大远景 → 中景                （由远及近，交代到人物）
✅ 全景 → 特写                  （强落差，强调）
❌ 中景 → 中景 → 中景            （三个一样，白拆）
❌ 大远景 → 特写 → 大远景        （两极乱跳，观众晕）
```

### 第 4 步：给每个镜头算时长

按第二章的四种情况：
```
空镜        5-7
单人说话    字数÷4 + 1~2
多人对话    5 起
完整动作    按动作长度
长镜头      8-10
```

### 第 5 步：写画面描述

按 5.1 的公式，一句到两句，看得见的才写。

### 第 6 步：补人物、台词、运镜、构图

```
人物    只写名字，没有写「无」
台词    没有写「本镜无台词」
运镜    一种主运镜，不写虚词
构图    2-6 字短词
```

### 第 7 步：补备注（资产清单）

```
这镜要出几样东西？人物 / 场景 / 道具，逐条列。
```

## 九、常见错误对照表

| ❌ 错误写法 | ✅ 正确写法 | 为什么 |
|---|---|---|
| 景别列写 `85mm 中长焦` | 写 `近景` | 分镜表不写焦段，转提示词时才配 |
| 台词列留空 | 写 `本镜无台词` | 留空会导致判断不出是漏写还是真没台词 |
| 建议时长写 `5s` | 写 `5` | 纯数字，单位在表头说明 |
| 一个分镜塞 5 个镜头 | 拆成两个分镜 | 说明里面装了两件事 |
| 每个镜头都写 3 秒 | 按动作和台词算 | 3 秒是下限，不是标准 |
| 画面描述写「他很悲伤」 | 写「他低着头，肩膀抖了一下」 | 心理活动拍不出来 |
| 运镜写「电影感运镜」 | 写「缓慢推近」 | 虚词不可执行 |
| 人物列写「穿红色棉袄的女孩」 | 写 `小梁` | 服装在定妆照解决 |
| 三个镜头景别全是中景 | 中景→中近景→特写 | 没递进 = 白拆 |
| 备注列空着 | 写 `人物资产：梁大` | 不写就不知道该生成什么 |
