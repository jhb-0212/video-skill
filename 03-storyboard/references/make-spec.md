# 制作层规范（剧本定稿后 → 分镜前 的交接物）

> 定位：本文件定义**两份剧本层交接物**（人物定妆单 / 剧本简介单）+ **一份分镜后交接物**（资产清单表）的字段规范。
> - **人物定妆单 + 剧本简介单**：剧本层 C5 产出，分镜前必须就绪。
> - **资产清单表**：**不在 C5 产出**——「出场镜头数 / 累计时长 / 镜头号」是镜头数据，剧本里数不出来。**由 `storyboard-table` 在分镜表定稿后统计产出**（见 storyboard-table 的「分镜后产出资产清单」节），字段规范以本文件第 3 节为准。
> 原则：三件都是「**提取**」不是「创作」——所有内容必须能在开发圣经或剧本里找到出处，不新造设定。
> **可独立用于已有剧本**：若用户已有定稿剧本、无开发圣经，本文件的两件（人物定妆单 + 简介单）仍按原字段执行——剧本没写的外貌细节，用 `character-design-sheet` 的 `feature-catalog.md` 按「身份 + 性格关键词」翻译补全（标「推断」或「待确认」），**不留空**。人物定妆单就是「已有剧本」场景下的人物一致性唯一来源。

## 一、人物定妆单

> 剧本定稿后第一件事，是把「人」定下来。AI 生成最大的坑是人物长相漂（同一场戏镜头一换脸就变），根子在没把人物「写死」。这份单子就是写死的地方。一旦定稿，全片所有人物的图、视频都必须照它做，不许中途漂移。

### 大型制作特殊要求：拆分「基础身份」与「状态变体（Delta）」

为了保证一百集里人物脸不崩，人物定妆单必须拆成两半：

1. **基础身份（ID + 三维视图 + LoRA）**：脸型、五官、骨相、肤色、永久疤痕（不包含衣服和当下妆容）。**必须落成一个唯一资产 ID（`CHAR-xxx`）+ 一套三维视图（正/侧/背）+ 一个专属 LoRA（锁脸训练源）**。基础身份一旦定型，全片唯一，不许变。
2. **状态变体（Delta）**：发型打理、服装、临时配饰、伤势、干湿状态。**只写「变化的部分（delta）」**，且**必须标注生效范围**（如：第 3-5 集穿夜行衣，第 6 集左臂包扎）。

在填下表时：
- “脸型五官/皮肤质感”属于基础身份（ID + 三维视图 + LoRA 锁死的部分）。
- “服装造型/发型发色”属于状态变体（Delta），请按集数分开列。
- 变体图必须以基础身份图（ID + 三维视图 + LoRA）为参考图，禁止让 AI 重新生成脸。

### 字段（每个有台词、有正脸、有戏份的人物，单独一行，全部填满）

| 字段 | 填写要求 |
|---|---|
| 姓名 | 用剧本原文名字，不许自己改字 |
| 身份定位 | 主角 / 配角 / 反派 / 见证者 / 群演（决定资产投入多少） |
| 年龄 | 具体数字，不写「中年/青年」，写「40岁」 |
| 性别 | 男 / 女，必填 |
| 身高体型 | 身高+胖瘦+肩宽体态，如「178cm，偏瘦，肩窄，站姿略含胸」 |
| 脸型五官 | 脸型+眼睛+鼻子+嘴唇+眉毛，逐项写，不能只写「长相普通」 |
| 发型发色 | 长度+造型+颜色，如「短发寸头，黑色，鬓角略长」 |
| 皮肤质感 | 肤色+纹理+有无特征，必须写「无痣无斑」，防止 AI 加斑点 |
| 服装造型 | 整套：上衣/下装/鞋/配饰，颜色材质款式都要写；多套则按场次分开列 |
| 性格关键词 | 3–5 个词，如「沉稳、寡言、护短、认死理」 |
| 行为习惯 | 标志性小动作，如「思考时摸下巴」「说话不看人眼睛」 |
| 说话方式 | 语速+音量+口头禅，如「语速慢，音量低，爱说『它不挑路』」 |
| 人物关系 | 和谁是什么关系，如「梁小是他弟弟」 |
| 情绪基调 | 全片主要情绪，如「全程隐忍，只在爆发时提高音量」 |
| 参考图 | 定妆图文件名 / 有无参考；有写文件名，无写「需生成」 |

### 三大铁律（踩坑换来的，必须守）

1. **一人一版，绝不换脸**：同一角色从头到尾只有一套面部特征，换装可以，换脸不行。
2. **面部干净光洁**：不得有光斑、亮斑、斑点、痘印、雀斑、疤痕、污渍；皮肤是一整片连续均匀的真实皮肤。
3. **群演各不相同**：一场戏多个人物时，长相、体型、年龄、服装全都不一样，必须有男有女，不许整齐划一。

> **光斑成因**：逆光 + 前景遮挡（树叶、窗格）最常产生光斑。室内或有前景时，改成「柔和正面补光，避免任何遮挡物投影在人物面部」。

### 填写示例（虚构人物，仅示范格式）
| 字段 | 示例内容 |
|---|---|
| 姓名 | 陈大山 |
| 身份定位 | 主角 |
| 年龄/性别 | 52岁/男 |
| 身高体型 | 172cm，壮实，肩宽背厚，站姿稳 |
| 脸型五官 | 方圆脸，眼皮内双，鼻梁塌而宽，嘴唇厚，眉毛粗短 |
| 发型发色 | 寸头，花白，两侧极短 |
| 皮肤质感 | 偏黝黑，粗粝，有风吹日晒的质感，无痣无斑 |
| 服装造型 | 深灰工装夹克（洗旧发白）、卡其工装裤、沾泥的劳保鞋 |
| 性格关键词 | 沉默、固执、护短、认死理、不认输 |
| 行为习惯 | 说话前先低头看一眼地面；紧张时用拇指搓食指 |
| 说话方式 | 语速慢，音量低，句子短，不说长句 |
| 人物关系 | 和老二是亲兄弟，两人多年不和 |
| 情绪基调 | 全程压抑，只在最后一场戏爆发一次 |
| 参考图 | 需生成（无参考图） |
> 示例的作用是「填成什么样算合格」的锚点——字段填满、每条有具体形状、不写「同上」。

### 交付标准

- 人物一个不漏，含只有几句台词的配角
- 每个字段都填满，不留空、不写「同上」
- 服装多套的，按场次分开列，标明第几幕穿哪套
- 定稿后全组共用，后续所有生成以它为准

## 二、剧本简介单

> 作用：让没读过剧本的人（客户/出资方/平台/制作组）30 秒内知道「什么故事、怎么讲、拍出来什么味道、多长」。简介写不好，剧本再好也没人看。
> 适配说明：本模板的「基本信息/分幕结构表」字段（总时长·幕数·镜头数·分幕时长占比）**面向短片（先导片 / TVC / 单集宣传片）**。若用于分集剧本（几十集），「总时长/幕数/镜头数」改为「总集数 / 单集时长 / 单集集均镜头数」，「分幕结构表」改为「分集钩子节奏表」（每集一个 D 节点 + 断点位置），其余字段（片名/类型/题材/风格/色调/参考作品/目标受众/用途/梗概/风格视听定调/主创）通用。

### 结构（五部分）

**① 基本信息**：片名 / 类型（短剧·漫剧·TVC·宣传片）/ 题材（一句话）/ 总时长（精确到秒）/ 幕数 / 镜头数 / 画幅（16:9 横版·9:16 竖版）/ 风格（视觉关键词）/ 色调（主色调+对比关系）/ 参考作品 / 目标受众 / 用途（成片放哪）。

**② 剧情梗概**：只写三件事——谁在哪想干什么；出了什么事打乱；最后怎么解决落到哪。字数 150–300，超 300 说明没提炼清楚。禁止流水账，要能听出「钩子」，听完没有追后文冲动就重写。

**③ 分幕结构表**：每幕一行，写清「幕次 / 讲什么 / 镜头数 / 时长 / 时长占比 / 作用」。这是导演和剪辑的施工图。比例参考（3–5 分钟短片）：建立 10–15%、蓄力 25–30%、高潮 30–40%、释放 15–20%、点题约 5%。**高潮段必须占最长，否则节奏塌，回改结构**。

**④ 风格与视听定调**：视觉风格（写实/动画/二次元/国风/电影感）/ 色调方案（冷暖主调与交替点）/ 光影逻辑（自然光/人工光/逆光/侧光）/ 镜头语言（景别/运镜/慢镜）/ 声音设计（音乐风格/关键音效/旁白）/ 节奏（快切/长镜）/ 禁忌（这片绝对不能出现什么）。

**⑤ 主创与交付**：
| 项目 | 内容 |
|---|---|
| 编剧 | |
| 导演/监制 | |
| 制作周期 | |
| 交付版本 | 成片 / 分镜表 / 资产包 / 剧本 |
| 交付平台 | |
| 版权归属 | |

## 三、资产清单表

> 剧本里出现过的每一样东西，都得有人做、有地方存、有编号。这张表就是开机前的账本：几个角色、每个出场几次、在哪儿场戏、几个场景、几样道具。做不全，剪到一半发现缺一个背景、缺一件衣服，整条线就得停。
>
> **产出时机（A1）**：本表**不在剧本层 C5 产出**——「出场镜头数 / 累计时长 / 镜头号」是镜头数据，剧本只有「场」没有「镜头」。**由 `storyboard-table` 在分镜表定稿后统计产出**，所有字段一次填满。
>
> **用法**：剧本定稿 → 出人物定妆单 + 简介单 → 做分镜表 → 用分镜表数据统计本表 → 喂给 `character-design-sheet` 的 `asset-tiering.md` 判级。

### 3.6 资产命名规则（强制）

文件名统一格式：**编号_名称_版本_扩展名**

示例：`P01_梁大_v1.png` ｜ `S03_冰湖_v2.png` ｜ `D01_陆巡_v1.png`

**要求**：
- **编号必须和本表一致，不许自创**
- **名称用剧本原文，不许改字、不许用拼音缩写**

> 命名乱是资产混乱的第一原因。三个人的定妆图都叫「新建文件」「IMG_7083」，一周以后没人分得清谁是谁。

## 与剧本层的关系

- 人物定妆单 + 剧本简介单是剧本层 C5 阶段「提取」产出的配套件，字段与铁律以本文件为准。
- 产出顺序：**剧本定稿 → 做人物定妆单 + 简介单 → 再拆分镜** → **用分镜表数据统计资产清单表**。分镜表只引用资产编号，不重复描述。
- 它们是剧本层 → 制作层（分镜/成片）的**标准接口**。后续制作层 Skill（分镜/构图/成片）应直接消费本文件定义的三份清单——其中**人物定妆单 + 简介单在剧本层 C5 产出，资产清单表在分镜后由 storyboard-table 产出**。

## 与下游两个 skill 的交接

本文件产出的三件中，两件是下游 skill 的输入：

| 本文件产出 | 下游 skill | 怎么用 |
|---|---|---|
| **人物定妆单**（15 字段） | `character-design-sheet` | 进提示词层时，用 `feature-catalog.md` 把「脸型五官」展开到具体类型（如「鹅蛋脸、开扇形双、薄唇」）、把「性格关键词」用三步法翻译成「眼神+表情+姿态」。**本单是输入，feature-catalog 是展开工具。** |
| **资产清单表**（由 `storyboard-table` 在分镜后统计产出） | `character-design-sheet` | 进 `asset-tiering.md` 判级时，本表的「出场镜头数 + 特写数 + 累计时长」是「镜头权重 + 特写频率」的**定量依据**——镜头多/特写多/时长长的升 L0/L1，少的降 L2/L3。**数据来自分镜表，不是从剧本估。** |
| **人物定妆单 + 资产清单表** | `storyboard-table` | 分镜表的「人物」列只写名字，长相从本单取；**分镜表是资产清单表的镜头数据来源**——分镜完成后，由分镜环节统计每个角色的出场镜头数 / 特写数 / 时长 / 镜头号，回填本表人物清单。 |
| **简介单** | 不直接进资产/分镜 skill | 是给客户/平台看的门面文档。 |

**不重复判级、不重复描述**：资产清单表的镜头/时长由分镜环节统计，下游 asset-tiering 直接用；人物定妆单已经定了长相，下游分镜表和提示词都只引用、不重写。
