# 人物特征分类清单（告别 AI 脸 · 完整词典）

> 用途：生成人物提示词时，**逐项填满**下面的维度，避免产出「千篇一律的 AI 脸」。
> AI 脸的根因是「没告诉 AI 这张脸长什么样」。本清单就是把人物写「具体」的词典，几乎覆盖人物描写的全部维度。

|---|---|

| 脸型（男/女各六类） | 二、脸型 |
| 五官（眉/眼/鼻/唇/耳） | 三、五官 |
| 发型（三要素+发色） | 四、发型 |
| 身材 / 服装 / 妆容 / 配饰 | 五~八 |

| **骨相怎么写到锁得住脸** | 「核心原则」的「骨相具体化」条 |
| **抽象气质词怎么翻译成具体动作**（最关键） | 文末「通用三步法」（先读）+「抽象气质词→具体动作翻译对照表」（后查） |

> 写人物时按需跳读对应节；遇到表里没有的气质词，用文末「三步法」现译。

---

## 核心原则

- 别写「一张好看的脸 / 漂亮的眼睛 / 身材好」这类空话。
- 每个维度都要**选一个具体类型**，例如「心形脸、下颌尖、颧骨适中」「狐狸眼、上挑眼尾、双眼皮、眼神凌厉」。
- **【铁律】形容词定方向 + 具体动作定执行**。形容词（清贵、落拓、疏离、机灵、凌厉、深邃、温柔、冷冽）单独写，AI 只会画成模糊的路人脸；但它能定"气质方向"。正确做法是**先写氛围词给方向，再紧跟「哪个部位 + 做出什么可见的动作/形状」锁执行**，两者结合：
  - ❌ 错误：「眼神凌厉」→ AI 不知道"凌厉"长什么样。
  - ✅ 正确：「眼神凌厉，眼睛微微眯起，眉毛压低，眼珠直视前方不偏移」。
  - ❌ 错误：「落拓风骨」→ 只写形容词，画不出。
  - ✅ 正确：「气质落拓，肩膀放松往下沉，脊背挺直，重心压在一只脚上，双手自然垂在身侧」。
  - 翻译口诀：**气质词（定方向）→ 眼神（看哪、睁多大）+ 表情（嘴角/眉/下颌怎么做）+ 姿态（肩/背/重心/手脚怎么放）**，动作是主体、形容词是点缀。
- **【骨相具体化】脸型 + 眼型至少锁两项，且自洽**。「骨相具体化」是防 AI 脸最有效的一步——只写「五官精致、东方美人」会出通用脸；写到「脸型 + 眼型」这一档，脸才锁得住；写到「鼻梁 + 唇形」是加分，但收益不如脸型眼型大。**具体骨相必须是一组自洽的组合**，不能互相矛盾（如「中庭偏长 + 鹅蛋脸 + 圆杏眼 + 尖下巴」是打架的，模型会各取一半，比不写还差）。**3D 国漫（D1）尤其要用这一条**——国漫最易出「通用国漫脸」，骨相不写具体就压不住。
- 优先级（决定辨识度的强弱）：
  1. **脸型 + 五官（眼/鼻/唇/眉）** —— 最强，决定「像不像」
  2. **发型（长短+造型+发色）** —— 很强，换发型 = 换人
  3. **身材 + 服装 + 肤色** —— 中强，决定整体气质
  4. **妆容 + 配饰 + 特殊体征** —— 加分项，拉开差异的「点睛之笔」
- 用户设定的**抽象气质词**要翻译成具体类型（见文末「用法提示」）。

## 一、基础项（人物段最前面的锚点）

- **年龄**：少年 / 青年 / 中年 / 老年（可带具体岁数，如「23岁」「40-55岁」）
- **性别**：男 / 女
- **肤色基调**：白 / 麦色 / 古铜 / 深棕 / 黑
- **肤色冷暖**：冷白 / 暖黄 / 中性
- **肤质**：清透无瑕 / 有雀斑 / 有痘印 / 粗粝 / 婴儿肌 / 有皱纹
- **整体气质 / 情绪基调**：冷冽 / 温柔 / 狂傲 / 忧郁 / 机警 / 呆萌 / 痞气 / 端庄

## 二、脸型（男 / 女各六类）

### 男性脸型
- **圆形脸**：线条圆润、腮帮饱满，年轻亲和，适合温和型角色
- **方形脸**：下颌线分明、颧骨方正，硬朗阳刚，适合硬汉/成熟男性
- **长形脸**：脸长偏窄、下巴偏长，清瘦理性，适合文艺/精英
- **心形脸**：额头偏宽、下巴尖削，精致清秀，适合年轻帅气男主
- **菱形脸**：颧骨突出、太阳穴与下巴收窄，立体有棱角，适合模特/反派
- **椭圆脸**：比例匀称、轮廓柔和，百搭耐看（最接近 AI 默认脸，慎用——易撞脸）

### 女性脸型
- **圆形脸**：肉感柔和、减龄可爱，适合甜美/少女
- **鹅蛋脸**：线条流畅、比例标准，古典耐看，最适合古装美人
- **方脸**：下颌略方、气场强，适合御姐/职场强势女性
- **心形脸**：额头宽下巴尖，精致甜美，适合女主角/网红脸
- **长脸**：纵向拉长、成熟理性，适合知性/高冷
- **菱形脸**：颧骨突出、骨骼感强，高级模特脸，适合时尚/冷艳

## 三、五官（眉 / 眼 / 鼻 / 唇 / 耳）

### 眉毛
- 眉形：一字眉、柳叶眉、挑眉、剑眉、弯眉、野生眉、断眉
- 浓淡：浓眉 / 淡眉 / 细眉 / 粗眉
- 眉距：眉心近（显严肃）/ 眉心宽（显开朗）
- 气质：剑眉显英气，柳叶眉显柔美，挑眉显俏皮/挑衅

### 眼睛
- 眼型：桃花眼、杏眼、丹凤眼、柳叶眼、狐狸眼、圆眼、下垂眼、上挑眼
- 眼距：近眼距显聚精，宽眼距显天真
- 双眼皮：平行双、扇形双、内双、单眼皮
- 眼神/气质：温柔、凌厉、无辜、深邃、冷冽、含情
- 特殊：异色瞳、瞳孔颜色、眼神光、眼白比例

### 鼻子
- 鼻型：高挺鼻、小巧翘鼻、直鼻、鹰钩鼻、蒜头鼻、宽鼻梁、细窄鼻
- 鼻头：圆润、尖翘、肉感
- 整体气质：立体高挺显英气，小巧精致显秀气

### 嘴巴
- 唇形：薄唇、厚唇、M 型唇、微笑唇、樱桃小嘴、宽唇
- 唇色/质感：自然裸色、红润、干裂、水润
- 表情气质：抿唇、微张、浅笑、冷冽

### 耳朵
- 耳型：贴耳、招风耳、圆耳、尖耳（精灵耳）、耳垂大小
- 特征：耳垂厚薄、耳骨形态、有无耳饰

## 四、发型

### 男性常见发型
- 寸头：极短利落硬朗，硬汉/运动型
- 板寸/圆寸：贴头皮，刚毅干练，军人/警察
- 短发背头：刘海后梳露额头，成熟精英，商务/霸道总裁
- 中分/三七分：复古绅士，文艺/民国风
- 侧分油头：发丝油亮服帖，精致复古
- 碎发/自然刘海：微卷细碎垂额前，少年感，青春男主
- 中长发扎起：半长扎髻束发，艺术家气息
- 长发披散：及肩或更长，颓废文艺/古风侠客

### 女性常见发型
- 及腰长发：顺直垂落，温柔女神，古典美人/女主角
- 大波浪卷：丰盈弹性，妩媚成熟，御姐/都市丽人
- 小卷/羊毛卷：蓬松凌乱，俏皮减龄，甜美少女
- 齐肩中长发：清爽利落，知性干练，职场女性
- 锁骨发/内扣：发尾内收，显脸小，百搭
- 短发波波头：齐耳圆润，复古可爱，活泼少女
- 高马尾：利落精神，运动活力，清纯校花/动作女主
- 双马尾/麻花辫：少女感、邻家，可爱路线
- 盘发/丸子头：干净优雅，古典/端庄

### 发型三要素（写全才不撞）
- **长短**：超短 / 齐耳 / 齐肩 / 及胸 / 及腰 / 及臀
- **造型**：直发 / 卷发 / 波浪 / 编发 / 盘发 / 扎发 / 半扎 / 碎发
- **氛围**：蓬松 / 服帖 / 凌乱 / 清爽 / 油亮

### 发色
- 自然黑、深棕、浅棕、栗色、亚麻、金发、银白、红色系（酒红/枫叶红）、蓝色系、粉色系、紫色系、灰调
- 深浅谱系：黑 → 棕 → 亚麻 → 金（由深到浅）
- 写法：「深栗色微卷长发」，而非「棕色头发」

## 五、身材

> **身材描述原则（D1）**：写「整体比例 + 曲线走向」，不直接写性征——直接写性征易触发平台过滤（尤其中文模型）或让 AI 过度性化。
> - ❌ 「胸大」「腿细」「腰细」
> - ✅ 「沙漏型身材，上身曲线明显，腰部收束明显，腿部修长匀称」
> - ✅ 英文：`hourglass figure, defined waist, elegant upper body curves, long slim legs`
> - 如需强调丰满感，用「丰腴型」「上身曲线饱满」而非直接写「胸大」。

### 男性身材
- 倒三角：肩宽腰窄、肌肉发达，阳刚健硕，硬汉
- 匀称精瘦：肌肉线条清晰不过度，清爽健康，运动男主
- 清瘦高挑：骨架偏细、身形修长，文艺斯文
- 魁梧壮硕：体格庞大、肩背厚实，保镖/战士

### 女性身材
- 沙漏型：上身曲线明显、腰部收束明显，曲线优雅，御姐
- 梨形：上身纤细、下身丰满，温婉柔美
- 苹果型：腰腹偏圆、四肢较细，亲和圆润
- 直筒/矩形：肩腰臀曲线不明显，清瘦高挑，模特冷淡风
- 纤细型：整体偏瘦、骨架小，清新少女

### 身体部位细节

> **注（D1 补充）**：下表「胸部/腰部/腿型」选项是**理解人物的工具词典**，供判型参考；**写 prompt 时用整体比例替代**（如「沙漏型身材，上身曲线明显」），不直接写部位性征。

- 胸部：丰满 / 适中 / 平坦
- 腰部：纤细 / 有肉感 / 沙漏曲线
- 腿型：长直 / 纤细 / 匀称 / 有力量感 / 肌肉修长
- 肩颈：直角肩 / 溜肩 / 宽肩 / 窄肩
- 身高比例：高挑 / 娇小 / 模特比例 / 婴儿肥

## 六、服装（上装 / 下装 / 外套 / 鞋 / 面料 / 配色）

> 服装是「妆造」段的核心。只写「穿衣服」没用，要写款式 + 颜色 + 材质 + 风格。

### 款式分类
- **领型**：圆领、V 领、立领、翻领、一字领、高领、交领（古装）
- **袖型**：长袖、短袖、无袖、泡泡袖、灯笼袖、广袖（古装）
- **衣长**：短款、及腰、及臀、及膝、及踝、长袍
- **下装**：长裤、短裤、裙（A字/包臀/百褶/长裙/短裙）、工装裤、牛仔裤
- **外套**：夹克、风衣、大衣、西装、牛仔外套、披风、斗篷
- **鞋**：运动鞋、皮鞋、靴子（工装靴/长靴/短靴）、帆布鞋、凉鞋、布鞋、绣花鞋（古装）

> **露肩描述谨慎（D3）**：古装/现代装写露肩时，用「一字领」「抹胸式领口」「露出肩颈线条」而非直接写「露肩」，并在 prompt 加 `elegant shoulder line`、`classical neckline` 这类安全词，避免触发「暴露」审核。

### 面料质感
- 棉、麻、丝绸、皮革、针织、牛仔、呢料、雪纺、蕾丝、亚麻提花
- 质感词：柔软 / 挺括 / 垂坠 / 厚重 / 轻薄 / 哑光 / 亮面

### 配色与花纹
- 纯色 / 撞色 / 渐变 / 格纹 / 条纹 / 印花 / 刺绣 / 暗纹提花
- 色彩情绪：黑白灰冷淡、莫兰迪温柔、高饱和张扬、大地色沉稳

### 风格标签
- 古风 / 现代 / 赛博朋克 / 军装 / 学院 / 街头 / 商务 / 运动 / 民族 / 蒸汽朋克

## 十、情绪与神态

- **情绪基调**：冷漠 / 温柔 / 狂傲 / 忧郁 / 机警 / 呆萌 / 痞气 / 端庄 / 疯批
- **眼神光**：有神 / 空洞 / 泪光 / 锐利
- **微表情**：挑眉、抿唇、勾嘴角、皱眉、眯眼、似笑非笑
- 注意：情绪写在「人物段」而非靠姿势硬凹；抽象气质翻译成「表情 + 眼神」具体描写。

> **高风险情绪词安全替代（D2）**：部分词有审核风险，写 prompt 时优先用替代方案或纯动作描述：

| 原词 | 风险 | 替代方案 |
|---|---|---|
| 杀意 | 暴力审核 | 「凌厉」「寒冽」「压迫感」；或纯动作「眉压低、眼微眯、嘴角平直」 |
| 妖冶阴柔 | 性别/性化审核 | 「俊美锋锐」「眼尾上挑、眼波流动」「华丽暗黑系」 |
| 破碎魅惑 | 性化审核 | 「脆弱感」「易碎感」「忧郁疏离」 |

## 十一、年龄与年代感

- **年龄锚定**：少年感（胶原蛋白、圆润）、青年（轮廓分明）、中年（细纹、法令纹）、老年（皱纹、眼袋、白发）
- **皮肤纹理**：光滑 / 有细纹 / 有皱纹 / 有老年斑
- **年代感**：古代 / 民国 / 现代 / 未来 / 架空

## 十二、特殊体征（高辨识度，谨慎使用）

- 疤痕、胎记、纹身、雀斑、痣
- 断眉、异色瞳、白化、义眼、义肢

## 十三、填满清单（Check List）

生成人物提示词前，逐项确认：

- [ ] 基础项：年龄 / 性别 / 肤色（冷暖+肤质）/ 气质基调
- [ ] 脸型（男/女六类）选一个
- [ ] 五官：眉、眼、鼻、唇、耳各选一个
- [ ] 发型：长短 + 造型 + 发色，写清楚
- [ ] 身材：体型 + 肩颈/胸/腰/腿部位特点
- [ ] 服装：款式 + 面料 + 配色 + 风格标签
- [ ] 妆容（女性角色优先考虑）
- [ ] 配饰：耳环、戒指、手表、项链、眼镜、帽子，按需添加
- [ ] 姿态 / 情绪神态（定妆照/全身图用）
- [ ] 特殊体征（如有，1~2 个）
- [ ] （最关键）一张人物参考图 + 一张服装参考图喂给 AI

---

## 用法提示

- 用户给的角色设定往往**只给了「气质/性格」等抽象词**（如「清贵相」「吊儿郎当」），缺少具体脸型/五官。本清单用来把这些抽象词**翻译成具体的眼型/鼻型/唇形/脸型**。
- 翻译示例：
  - 「清贵相」→ 长形脸 + 高挺直鼻 + 薄唇 M 型 + 眉骨高 + 桃花眼（三分疏离）
  - 「吊儿郎当」→ 表情挑眉 + 眼神机警，而非五官本身
  - 「硬汉」→ 方形脸 + 鹰钩鼻/宽鼻梁 + 寸头 + 倒三角身材
  - 「御姐」→ 鹅蛋脸 + 狐狸眼（上挑眼尾）+ 高挺鼻 + 厚唇 + 大波浪卷 + 沙漏身材
  - 「少年感」→ 心形脸 + 杏眼（圆润）+ 碎发自然刘海 + 匀称精瘦
- 若用户设定已写清五官，则直接取用，无需硬套分类。
- **不要一次把十二个维度全塞满**——按「优先级」和「角色需要」取舍，避免 prompt 过载反而跑偏。基础项 + 脸型 + 五官 + 发型 + 身材 + 服装是必填，妆容/配饰/特殊体征按需。

## 抽象气质词 → 具体动作 翻译对照表（关键：形容词定方向 + 动作定执行）

> 抽象词**单独**写进 prompt，AI 只会画成路人脸；但抽象词**紧跟具体动作**时，能给画面定"气质方向"。正确用法是**两者结合**，不是二选一。

### 通用三步法（遇到表里没有的词，用这个方法现译，不用等词典扩充）

对照表只能覆盖常见的词，遇到「阴鸷/憨直/疯批/病娇/疏狂」这类表里没有的，按下面三步**现场翻译**，方法论是通用的：

1. **判断情绪基调（冷/暖/锐/钝）**：这个词给人的感觉是冷的还是暖的、是尖锐的还是圆钝的？例如「阴鸷」= 冷 + 锐；「憨直」= 暖 + 钝；「疯批」= 锐 + 不稳定（冷热交替）。
2. **基调 → 眼神/表情/姿态**：把冷/暖/锐/钝翻译成可见动作——冷→眼神收敛、表情平、肩背收；暖→眼神放松、嘴角上扬、肩松；锐→眼睛眯、眉压低、下颌绷；钝→眼睛圆睁、表情憨、肩圆含胸。
3. **再落到脸型/五官**（可查本文件前文分类词典）：锐气角色常配长脸/菱形脸/剑眉/上挑眼；钝感角色常配圆脸/椭圆脸/一字眉/圆眼。把情绪落到具体的脸型和五官形状上。

> 三步法的产出格式，和对照表一致：**眼神（看哪/睁多大）+ 表情（嘴角/眉/下颌）+ 姿态（肩/背/重心/手脚）**，再叠加脸型/五官。

### 为什么「只用形容词」是陷阱、以及正确用法（辨析）

网上那些「草莓甜酷 / 奶甜系 / 清冷甜辣 / 精致少女感」的提示词，看起来专业，其实分两部分：

- **真正起作用的，永远是具体可画的东西**——眼睛颜色、瞳孔、睫毛长短、刘海走向、发长、发色、服装款式、配饰。这些 AI 能照着画。
- **那堆形容词**（甜酷/清冷/奶甜/少女感），AI 只是**随机挑一张好看的甜妹脸**，换种子就是另一个人。它单独出现 = 出「随机的好看」，不是「你要的那个特定的人」。

**但形容词不是"无效"，而是"不可控"**——它能定方向（让画面往"清冷"或"甜酷"偏），只是偏到哪一步控制不了。

**正确结论（两者结合）**：
1. **形容词定方向 + 具体动作定执行**：先写一个氛围词给方向（如"气质清冷"），再紧跟"眼神/表情/姿态"的具体动作锁死执行。动作是主体，形容词是点缀。
2. 要「指定气质」→ 形容词 + 动作都写，动作不能省。
3. 要「随机好看」→ 才堆形容词（抽卡），那不是定妆。
4. 学网上优秀 prompt 时，**学它把「瞳孔/睫毛/刘海/发长/服装」这些具体细节写得多细**，氛围形容词只借鉴它"定方向"的作用，别学"堆一堆形容词不拆动作"。

> 本技能做的是「定妆」（指定具体角色），所以：形容词可以出现，但**出现后必须紧跟具体动作拆解**，只写形容词不拆动作 = 白写。

| 抽象气质词 | 眼神（看哪/睁多大） | 表情（嘴角/眉/下颌） | 姿态（肩/背/重心/手脚） |
|---|---|---|---|
| 清贵 / 疏离 | 眼神不聚焦镜头，微微向下或向侧，眼珠不四处乱看 | 嘴角平直或微向下，下颌微收，面部放松不紧绷 | 肩放松下沉，脊背挺直，重心略偏一侧，站得随意但有型 |
| 吊儿郎当 / 痞气 | 眼神带点戏谑，眼角微挑 | 嘴角一侧微翘、似笑非笑，眉头微挑 | 肩膀一高一低或重心压一只脚，手插兜或自然垂放 |
| 机灵 / 狡黠 | 眼睛微睁、眼珠有神、视线略偏 | 嘴角上扬，眉微挑 | 头微微歪一点 |
| 冷冽 / 凌厉 | 眼睛微眯，眼珠直视前方不偏移 | 嘴唇抿紧，下颌线绷，眉头压低 | 肩线绷直、站得笔挺，重心稳 |
| 温柔 / 含情 | 眼睛放松、眼尾略弯、视线柔和 | 嘴角自然上扬，眉舒展 | 肩放松，头微微偏向一侧 |
| 落拓 / 随性 | 眼神放松、不刻意 | 嘴角似笑非笑，面部松弛 | 肩膀下沉、脊背不刻意绷、重心偏一侧、手自然垂 |
| 坚定 / 认死理 | 眼珠直视前方、不闪躲 | 下颌收紧、嘴唇抿紧 | 脊背挺直、双脚站定不晃 |
| 憨厚 / 老实 | 眼睛圆睁、眼神直接 | 嘴角憨笑、眉毛平 | 肩圆、微微含胸、站得放松 |
| 狡诈 / 算计 | 眼睛半眯、眼珠斜视一侧 | 嘴角一边勾、似笑非笑 | 头略低、肩微耸 |

**套用方法**：拿到角色的性格关键词，先在本表找对应的「眼神/表情/姿态」，把这三条**原样写进 prompt 的「姿态/神态」段**，再叠加脸型/五官。不要在 prompt 里保留「清贵」「疏离」「机灵」这些原词。

## 高难词中英翻译对照（B7：英文模型不写中文气质直译）

> 中文里很多词英文没有直接对应，直译会让英文模型瞎猜（如「桃花眼」→ `peach-blossom eyes` 被理解成粉色的眼）。**原则：英文提示词不写中文气质的直译，写「看得见的具体形状」。**
>
> **关于直译词**：下表「直译」列标的是「**不可单独使用**」，不是「完全禁用」。直译词可作为**辅助氛围词**保留，但必须**紧跟**具体形状描述（如 `peach-blossom eyes, upturned outer corners, double eyelids`）——单独写直译会跑偏，直译 + 形状描述才能既锁气质又锁形状。案例二的 `peach-blossom eyes, upturned outer corners, double eyelids` 就是这个正确用法。

| 中文 | 直译（不可单独使用） | 英文模型可用的替代表达 |
|---|---|---|
| 桃花眼 | peach-blossom eyes | eyes with upturned outer corners, watery and expressive, thick double eyelids, slight teardrop shape, romantic gaze；`peach-blossom eyes` 可作辅助词，但必须紧跟 `upturned outer corners, double eyelids` 等形状描述 |
| 丹凤眼 | phoenix eyes | narrow elongated eyes, outer corners tilted up sharply, monolid or thin double eyelid；`phoenix eyes` 可作辅助词，但必须紧跟 `narrow elongated, outer corners tilted up` |
| 高颅顶 | high cranial top | tall rounded skull shape, more hair volume on top, head appears slightly taller, elegant head-to-body proportion |
| 窄长瓜子脸 | narrow melon-seed face | narrow oval face, pointed chin, slim jaw, forehead slightly wider than chin |
| 高鼻梁 | high nose bridge | tall straight nose bridge, defined nasal bone, narrow nostrils |
| 清贵相 | noble aloof look | refined bone structure, high brow ridge, thin lips, calm composed expression, upright posture；`noble aloof` 可作辅助词，但必须紧跟 `refined bone structure, composed expression` 等具体描述 |
| 落拓风骨 | disheveled but dignified | slightly unkempt yet upright, relaxed shoulders, straight back, dignified bearing despite casual posture |
