# 资产分级（Asset Tiering）—— 角色 L / 场景 S / 道具 P / 声音 M·F

> 用途：产任何资产（角色/场景/道具/声音 BGM）之前，先看文首速查表判级，再决定产哪些、产到什么深度。多数任务读速查表即可，要每级明细再往下读。
> 核心目标：**控制资产成本，避免无效过剩**——把预算投到刀刃上，低权重资产不做全资产包。

## 速查表（先读这个，半页）

| 线 | 级别 | 判据 | 最高级（全量） | 最低级（极简） |
|---|---|---|---|---|
| 角色 L | L0~L3 | 镜头权重/特写/换装/实体落地 | L0 主角：全套资产包 | L3 群演：单张定妆照 |
| 场景 S | S0~S3 | 出镜时长/戏份权重/搭景 | S0 主场景：全景+多角度+拆解 | S3 空镜：单张氛围 |
| 道具 P | P0~P3 | 剧情推进/特写/实体制作 | P0 核心道具：三视图+色卡+拆解 | P3 杂物：文字 |
| 声音 M·F | M0~M3 / F0~F3 | 情绪锚点/主线/复用/原创成本 | M0 主题/F0 核心音效：原创 | M3 底噪/F3 环境声：复用 |

**判级口诀**：特写多 + 换装 + 实体落地 → 升最高级；无特写 + 单造型 + 氛围性 → 降最低级；音频则「情绪锚点 + 主线 + 复用 → 原创，否则版权库复用」。

**共同红线**：工程信息优先 + 禁止假拆解 + 原创只给锚点余者复用 + 色卡按需（≤5 类）。

## 一、核心原则

**按镜头权重、特写频率、是否换装、是否需要实体落地（cos / 服装打版 / 3D 资产）分级，控制资产成本，避免无效过剩。**

- **镜头权重**：角色在片/游戏里的戏份占比、出镜时长。
- **特写频率**：角色被近景/特写镜头拍脸、拍细节的频率。特写越多，脸和细节越要抠。
- **是否换装**：有多套造型的角色，每套都要独立设定，成本翻倍。
- **是否实体落地**：要 cos / 打版 / 建模的角色，需要工程级设定（三视图、拆解、色卡、尺寸），成本远高于纯画面用设定。

**判级口诀**：特写多 + 换装 + 实体落地 → 升 L0；无特写 + 单造型 + 氛围性 → 降 L3。

## 二、分级定义（L0~L3）

### L0｜核心主角（1~2 人）

> 双线贯穿角色、大量特写、多套造型、有打戏/换装、与关键道具互动。

**✅ 全套资产包（精简版，剔除细碎冗余，保留生产可用信息）**

1. **主角色立绘**：正面、完整造型、光影统一。

> **【工程红线】状态变体（Look Variant）强制隔离**：大型制作中，换装、受伤状态改变，**绝不允许在同一个 prompt 里描述两套状态**。
> - **基础立绘**：只做一套基础造型（用于锁定脸部特征和训练 LoRA）。
> - **状态变体图**：每换一套服装/受伤，单独出一张变体图。提示词只写 delta（变化的部分），强约束“脸、发型、身形不变”。如 `V01_夜行衣`、`V02_左臂受伤`。

> **【状态变体六问】（借鉴 `short-drama-image-prompts`，每个变体条目必须能回答）**：只写「生效范围」不够，一个变体要交代清「从哪来、变什么、到哪恢复、牵连谁」：
> 1. **Base（基底）**：从哪个准确身份/变体 ID 派生？（如 `CHAR-001 + V00 基础造型`）
> 2. **Preserved anchors（持久锚点）**：哪些身份事实不变？（脸型、五官、骨相、永久疤痕——这些**锁死**，delta 不得触碰）
> 3. **Delta（变化）**：哪里、什么范围、什么程度变了？（如「左袖肘以下被雨淋深一度，肩部仍干」——有边界、可直接看到）
> 4. **Cause/source（来源）**：变化来自哪个场景/连续性事实/创作者决定？（如「第 6 集营救戏左臂被划伤」）
> 5. **Validity（有效范围）**：**从哪集开始 + 到哪集结束/恢复**？（三段，不是只写「开始」——如「EP006 受伤，EP008 包扎，EP010 痊愈」）
> 6. **Affected work（受影响工作）**：哪些镜头/关键帧/下游资产要同步用这个变体？（如「EP006-EP010 所有左臂出镜的镜头」）
>
> **常见失败**（六问缺失的症状）：只有「更脏/更老/更阴森」没有位置和范围；delta 覆盖全身实际已改身份却仍叫 variant；有状态但无 cause/validity，导致后续镜头不知何时复用；把 pose/机位/一次表情当成资产变体。

> **【DAM 资产管理与版本控制】L0 主角资产必须进 `05-data-center`**：百集级制作里，L0 主角的基准图、LoRA、三视图、变体图**必须落入 `05-data-center/bible/` 与 `05-data-center/versions/`**，不允许散落在个人桌面/临时目录。

> **【DAM 资产管理与版本控制】L0 主角资产必须进 `05-data-center`**：百集级制作里，L0 主角的基准图、LoRA、三视图、变体图**必须落入 `05-data-center/bible/` 与 `05-data-center/versions/`**，不允许散落在个人桌面/临时目录。
> - **基准图（锁脸）**：写入 `bible/characters.jsonl` 的 `base_ref_image`，供 `check_assets.py` 做 FaceID 比对。
> - **LoRA**：写入 `lora_path`，供下游模型锁脸。
> - **版本号强制**：每次重绘必须升版本号（`v1` → `v2`），旧版不删、留档回溯。文件名格式 `CHAR-001_梁大_v1.png`（见 `make-spec.md` 3.6 命名规则）。
> - **可追溯**：任何一张图，都能通过「资产 ID + 版本号」定位到它的生成批次、参考图、提示词，出问题可回溯到具体哪一版。

2. **三视图**：正面 / 侧面 / 背面。
3. **简化服装爆炸拆解图**：只拆**独立可拆卸组件**（发冠组、外袍、内衬、束腰、腰饰、披帛、下裙），**不拆分贴身小件**（不拆到丝袜、内衣这类微末单品）。
4. **重点特写 ×3**：头饰、腰封主纹样、衣身刺绣面料（按角色辨识度替换，非固定这三项）。
5. **材质样卡**：丝绸、薄纱、金属、刺绣、珠饰（**5 类以内，够用即可**）。
6. **标准配色卡**。
7. **表情参考集**（5 款：平静、冷厉、动容、淡漠、**凌厉/压迫感**——按角色情绪基调替换；**敏感平台不用「杀意」原词**，改「凌厉」或纯动作描述「眉压低、眼微眯、嘴角平直」，见 `feature-catalog.md` D2）。
8. **武器 / 专属道具设定**：单独小设定卡（如青玉印、佩剑等）。

**注意**：L0 的"全套"仍是**精简版**——剔除细碎冗余，保留生产可用信息，不再拆到丝袜这类微末单品。

**多套造型乘数（关键，别漏）**：上面的资产包默认按「一套造型」计。**多套造型的主角（如林梓泳有 4 套），立绘/三视图/配色卡要 × 造型数**——每套造型独立出立绘 + 三视图 + 配色卡；但**三视图/拆解/表情集不必全造型 ×N**：
- **每套造型都要**：主立绘 + 配色卡（锁该套造型的颜色/款式）。
- **只挑主造型（或实体落地的那套）做**：三视图、服装拆解、材质样卡（工程级资产只给最需要落地的那 1~2 套，其余套造型给立绘+色卡即可）。
- **表情集 / 道具卡不分造型**：脸和道具跟造型无关，做一份即可。
- **判级口诀补充**：换装套数越多，立绘/色卡越多，但工程级拆解仍只投在刀刃造型上，避免「每套都拆」的无效过剩。

**主造型怎么定（优先级，从高到低）**：
1. **实体落地那套**（要 cos / 打版 / 3D 建模的那套）——工程级资产（三视图/拆解/色卡）永远优先做这套。
2. **戏份最多那套**（出场时长最长、海报/定妆主打的那套）——纯画面用途时选这套。
3. **海报/主视觉那套**（宣传物料、封面那套）——前两者都不适用时选它。
- **冲突时的处理**：若「实体落地套 ≠ 主造型套」，**两套都做三视图**——一套供打版（工程信息），一套供画面（视觉锚点），其余套仍只给立绘+色卡。

### L1｜重要配角

> 有独立剧情线、高频出场、少量特写、1~2 套造型。

**中档资产包**

1. **主角色立绘**（正面、完整造型）。
2. **三视图**：正面 / 侧面 / 背面。
3. **标准配色卡**。
4. **表情参考集**（3 款）。
5. **关键道具设定卡**（有专属道具才做，无则省略）。

**不做**：服装爆炸拆解图、材质样卡（无实体落地需求时省略）。

---

### L2｜功能配角

> 固定出场、无特写、单套造型、无换装。

**基础资产包**

1. **主角色立绘**（正面、完整造型）。
2. **正面 / 背面双视图**（非完整三视图）。
3. **配色卡**。

**不做**：三视图（只做双视图）、拆解、材质、表情集、道具卡。

---

### L3｜群演 / 路人

> 氛围性、无台词（仅环境人声）、不换装。

**极简资产**

1. **单张定妆照**（或仅文字设定）。
2. **面部各不相同**（群演铁律：人物面部须各不相同，防止撞脸）。

**不做**：其余一切资产。

## 四、配套规则

### 1. 设定图统一规范

- **画幅**：9:16 竖版 / 16:9 横版**可选**（按图种与用途定，不写死）。
- **标注色卡**：所有设定图（尤其三视图/拆解图/配色卡）**必须标注色卡**——主体及各组件给出 Hex 色值或明确色名，便于打版 / 建模 / cos 取色。
- **色卡呈现模板（长什么样）**：色卡**优先标注在立绘/三视图图上，不单独出图**——在图的底部排一排色块，每块下方标「Hex + 色名 + 对应部件」。描述性示例：

  > 图底部一排色块，从左到右：`#2B2B2B` 墨黑 · 外袍主色 / `#C9A86A` 暗金 · 腰封纹样 / `#E8E4DC` 米白 · 内衬领缘 / `#6B5B45` 深棕 · 护腕皮革 / `#1A1A1A` 玄黑 · 发色。

  写法要点：每个色块 = **Hex（#RRGGBB）+ 色名 + 对应部件**，三要素缺一不可，按「主色在前、辅色在后」排序。

- **色卡适用范围（哪些资产需要、哪些省略）**：
  - **需要**：L0/L1/L2（角色）、S0/S1（场景）、P0/P1（道具），以及一切**实体落地**类资产（cos/打版/3D 建模/搭景/道具制作）。
  - **可省略**：L3 群演、S3 空镜、P3 杂物，以及纯画面参考（不做实体落地的图）——这些给文字色名即可，不必排色块。
- **工程信息优先于面板堆砌**：实体落地类设定，优先保证三视图、拆解关系、色卡、尺寸、装配顺序等工程信息正确，不要为"好看"堆装饰性面板、花字、假 UI。

### 2. AI 生成设定禁止假拆解

- **假拆解**：AI 把一件衣服画成"炸开的一堆碎片"，却拆不出真正可分离、可独立成立的组件——这是不可交付的假拆解。
- **真拆解必须满足**：
  1. 每个组件能独立成立（单独拿出去也完整）；
  2. 层叠顺序清晰（谁在外、谁在内、谁压谁）；
  3. 能一一对应回三视图。
- **可操作判定法（怎么检验是不是假拆解）**：把拆解图里的**每个组件单独裁出来**，看它是不是一个「完整的衣服部件」——
  - ✅ 合格：裁出来是一整件能穿的部件（一件外袍、一条腰带、一个发冠），且能看出它和相邻组件的层叠关系（谁压在谁上面、谁在谁内侧）。
  - ❌ 假拆解：裁出来只是「一片布 / 一块碎片」，看不出是哪个部件、也看不出层叠关系——这就是"炸开的碎片"，不可交付。
  - **判不出就降级**：裁出来既不是完整部件、也看不出层叠关系时，直接降级为「逐组件单独成图」，别硬拼一张爆炸图。
- **做不到就降级**：拆不出真组件时，降级为「逐组件单独成图」，不要硬拼一张"爆炸图"。
- 只拆「独立可拆卸组件」（发冠组/外袍/内衬/束腰/腰饰/披帛/下裙），不拆贴身小件。

### 3. 成本控制

- **按级产，不越级**：L2/L3 角色不做拆解、材质、表情集，避免无效过剩。
- **材质样卡 ≤5 类**：够用即可，不堆。
- **表情集按需**：L0 五款、L1 三款，情绪基调按角色替换，不照抄默认五项。
- **特写按需 0~3 个**：只挑最能体现辨识度的部位，没辨识度特写可省略。
- **先定妆后多视图**：先出单张立绘锁定形象，再把该图作参考图出多视图/三视图，避免反复随机刷新跑偏。

### 4. 文字处理政策（大字报/悬赏令/屏幕/牌匾）

> 大型制作中，**严禁让 AI 直接生成精确可读的文字**（极易乱码，后期修图成本极高）。资产分级时必须声明文字策略：
> - **`postproduction`（后期加字，最推荐）**：只让 AI 画出带有透视和材质的“空白牌匾/纸张”。在提示词中写：`悬赏令，纸张空白无字，不要出现任何字母或符号`。
> - **`symbolic`（图形占位）**：远景、虚焦画面，只生成类似文字的排版色块，不可读。
> - **`exact_readable`（精确可读，极不推荐）**：除非特写，否则不采用。必须时要在 prompt 里逐字写出，且加高权重。

> **【文字两层分离】（借鉴 `short-drama-image-prompts`，上面三档其实混了「两件事」）**：文字要拆成**两层**，不能混成一个枚举：
>
> **第 1 层——资产来源政策（资产负责人定，回答「剧情真相里这字到底是什么」）**：
> - `exact_readable`：有已接受的精确文字，需逐字引用
> - `graphic_only`：只有图形职责，无可辨字义
> - `no_readable_text`：剧情里就不该有可读文字
> - `pending_creator_text`：文字尚未由创作者确认
>
> **第 2 层——本次提示词呈现方法（提示词环节定，回答「这次图怎么处理这个真相」）**：
> - `readable`：逐字引用已接受文本，允许清晰可读
> - `symbolic`：保留文字感图形，明确不可辨字义
> - `blank`：承载面保持空白（但保留材料、透视、光照）
> - `postproduction`：预留干净区域，文字后期加
>
> **默认映射（来源政策 → 允许的呈现方法）**：
>
> | 资产来源政策 | 允许的呈现方法 | 要求 |
> |---|---|---|
> | `exact_readable` | `readable` 或 `postproduction` | 前者逐字引用；后者保留承载区 + 精确文字引用 |
> | `graphic_only` | `symbolic` | 保留图形存在/布局，不新造可辨字义 |
> | `no_readable_text` | `blank` 或明确不可读的 `symbolic` | 不得偶然造成新名字/号码 |
> | `pending_creator_text` | `postproduction` 暂存，或阻断 `readable` | 不猜文字，保留 unresolved 状态 |
>
> **铁律**：单个文字承载面不能同时选互斥政策；`readable` 与全局 no-text 冲突时必须先解决（不能一边要求可读、一边写「画面里不要任何文字」）。
>
> **【负面词清不掉参考图里已有的字】——最易被忽略的坑**：`不要文字` 这类负面词，只能管**输出**，**清不掉参考图里已经携带的字形、标牌、界面、水印或字幕残留**。若参考图本身带文字风险：
> - 先**裁切 / 清理 / 遮罩 / 替换**参考图；
> - 会破坏身份/地理/构图时，退回资产环节或选 `postproduction`；
> - **不得靠加更强的负面词假装风险消失**。
>
> **「语义上必须出现签名」≠「已有可复制的正式字形」**：只有签名归属或剧情职责、没有创作者确认的字形资产时，保留来源说明并阻断 `readable`，别用姓名/伪签名/自画笔画冒充正式字形。

## 五、判级流程（操作顺序）

1. 拿到角色列表，逐角色问四个问题：镜头权重？特写频率？是否换装？是否实体落地？
2. 对照速查表判级（L0~L3）。
3. 按级列出该角色「资产清单」。
4. 逐项资产套用 `prompt-templates.md` / `view-spec.md` 生成中英双份提示词。
5. 实体落地类资产补色卡与工程信息。

## 六、场景与道具：同一套分级逻辑

> 场景、道具与人物**同理**——按「重要度 / 使用频率 / 特写需求 / 是否实体落地」分级，不无差别全套产出。判级维度从人物的「镜头权重/特写频率/是否换装/是否实体落地」平移为场景/道具各自的「重要度/出镜频率/细节需求」。

### 场景分级

> **命名护栏**：本节的 `S0–S3` 是场景**重要度分级**（决定做多深），
> 与 `scene-system.md` 的 `SS0–SS5`（场景**叙事状态**）是两套编号，永不混用。
> 状态码写法 `SC-01@SS2`，绝不写 `SC-01@S2`。

> **画幅分层（S0/S1 必产出两张）**：S0/S1 场景必须产出「design plate（16:9）+ blocking ref（9:16）」两张；S2/S3 只出 design plate 单张。见 `scene-system.md` 文首画幅铁律。

| 级别 | 适用场景 | 资产深度 |
|---|---|---|
| **S0 主场景** | 贯穿全片、反复出现、承担关键戏（如主角居所、决战地） | 全景设定 + 多角度（平/俯/近）+ 关键结构拆解 + 材质/配色卡 + 道具陈设说明 + 光照/氛围参考 + **blocking ref（9:16）** |
| **S1 重要场景** | 多场戏、有固定功能（如青梧殿、夜市） | 全景设定 + 2~3 个角度 + 配色卡 + 氛围参考 + **blocking ref（9:16）** |
| **S2 过场场景** | 单场戏、一闪而过 | 单张全景设定（或仅文字描述） |
| **S3 氛围背景** | 纯背景/空镜 | 单张氛围图或复用已有 |

- **判据**：出镜时长 + 戏份权重 + 是否承担关键情节/美术卖点。
- **实体落地（搭景/UE 资产）**：需平面图、结构、尺寸、配色卡、道具陈设清单——工程信息优先。
- **统一规范**：标注配色卡与光照/时段说明（白天/夜/黄昏）。

### 道具分级

| 级别 | 适用道具 | 资产深度 |
|---|---|---|
| **P0 核心道具** | 贯穿主线、大量特写、有专属设定（如青玉印、佩剑） | 正面/侧面/背面三视图 + 材质/配色卡 + 尺寸比例 + 关键结构/铭文特写 + 使用态（手持/持握）参考 |
| **P1 重要道具** | 关键情节出现、有特写 | 正面/侧面 + 配色卡 + 尺寸 |
| **P2 一般道具** | 日常陈设、无特写 | 单张设定（或并入场景道具清单，文字描述即可） |
| **P3 氛围道具** | 背景杂物 | 文字描述或批量复用 |

- **判据**：是否推动剧情 + 特写频率 + 是否有专属设定/世界观锚点 + 是否实体制作（道具组/3D 打印）。
- **实体落地（道具制作）**：需三视图、尺寸、材质、配色卡、结构拆解——工程信息优先，AI 生成禁止假拆解（同人物拆解红线）。

### 通用原则（人物/场景/道具三线统一）

1. **先分级，再产资产**：三类资产都先判级，按级产，避免低权重做全套的无效过剩。
2. **工程信息优先于面板堆砌**：凡实体落地，优先三视图/拆解/尺寸/色卡等工程信息正确。
3. **禁止假拆解**：拆解必须组件独立成立、层叠清晰、可对应回三视图。
4. **色卡/材质样卡按需**：≤5 类够用即可。
5. **成本闸门**：核心（L0/S0/P0）才全量，过场/氛围（L3/S3/P3）只给极简或文字。

## 七、声音与 BGM：同一套分级逻辑

> 声音（音效 SFX / 配音 / 环境声）与 BGM（配乐）与人物/场景/道具**同理**——按「重要度 / 是否主线推进 / 是否情绪锚点 / 是否反复复用 / 原创成本」分级，不无差别全套原创。**音频的特殊之处**：判级维度多一个「原创 vs 版权库复用」，因为原创音乐成本远高于买/复用现成素材。

### 配乐 BGM 分级

| 级别 | 适用音乐 | 资产深度 |
|---|---|---|
| **M0 主题曲 / 核心配乐** | 贯穿全片的主旋律、片头/片尾/情感高潮锚点（如主角主题、双人主题） | 原创作曲 + 主题动机（motif）拆解 + 多情绪变奏（主题 + 变奏 2~3 版）+ 分轨/工程文件 |
| **M1 重要配乐** | 关键场次固定配乐（决战、重逢等有独立情绪） | 原创或精修版权库 + 单曲成片 |
| **M2 过场配乐** | 过渡、氛围铺垫 | 版权库选购或轻量原创 |
| **M3 氛围底噪** | 通用氛围、环境音 | 版权库素材或复用 |

### 音效 SFX 分级

| 级别 | 适用音效 | 资产深度 |
|---|---|---|
| **F0 核心音效** | 贯穿主线、有世界观锚点、反复触发（如青玉印催动、界门开启、佩剑出鞘） | 原创拟音 + 多版本 + 音效工程文件 |
| **F1 重要音效** | 关键动作/情节（打戏碰撞、施法） | 拟音或精修素材 |
| **F2 一般音效** | 常规动作（脚步、开关门） | 版权库素材 |
| **F3 环境底噪** | 背景环境声（夜市人潮、风声） | 素材库或现场收音 |

### 音频分级判据（区别于视觉资产）

- **是否主线推进 / 情绪锚点**：主题曲、主角主题动机 → M0；通用氛围 → M3。
- **是否反复复用（主题复用）**：一个 motif 反复变奏用的 → 高权重，值得原创；一次性过场 → 低权重。
- **原创 vs 版权库复用成本**：原创作曲/拟音成本高，只给 M0/F0 级别的核心锚点；其余优先版权库复用或轻量改编，避免无效原创。
- **世界观锚点**：有专属设定、能成为"声音符号"的音效（青玉印的特定音色）→ F0；无辨识度的通用音 → 低权重。

### 音频资产落地形式（提示词之外）

> 注意：本技能**不直接生成音频**，音频资产是「需求说明 + 分镜/情绪描述 + 参考样例方向」，交付给作曲/拟音/版权库检索使用。

1. **M0 主题**：给「主题动机描述（情绪/速度/调式/配器方向）+ 场景锚点 + 参考曲风」，供作曲。
2. **M1/M2**：给「情绪基调 + 时长 + 参考方向」，供选曲/精修。
3. **F0 音效**：给「触发场景 + 声音质感描述（拟音材料方向）+ 世界观锚点」，供拟音。
4. **其余**：给版权库检索关键词或素材清单。

## 八、四线统一分级总览

| 维度 | 角色 | 场景 | 道具 | 声音/BGM |
|---|---|---|---|---|
| 分级符号 | L0~L3 | S0~S3 | P0~P3 | M0~M3（配乐）/ F0~F3（音效） |
| 核心判据 | 镜头权重/特写/换装/实体落地 | 出镜时长/戏份权重/搭景 | 剧情推进/特写/实体制作 | 情绪锚点/主线推进/复用/原创成本 |
| 最高级（全量） | L0 主角 | S0 主场景 | P0 核心道具 | M0 主题/F0 核心音效 |
| 最低级（极简） | L3 群演 | S3 空镜 | P3 杂物 | M3 底噪/F3 环境声 |
| 共同红线 | 工程信息优先、禁假拆解 | 同左 + 光照/时段 | 同左 + 尺寸比例 | 原创只给锚点、余者复用 |

**核心心法（四线通用）**：先分级定「产什么、产多少」，再产提示词/需求说明；核心锚点才全量，过场/氛围只给极简；工程信息（尺寸/色卡/拆解/时长/调式）优先于花哨堆砌。
