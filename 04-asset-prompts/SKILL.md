# 角色/场景/道具/声音资产生产 —— 分级资产 + 提示词生成器

> **链路入口**：本 skill 是全链路第 3 环（资产层），全链路图 + 交接表 + 路由表见 `01-pipeline-orchestrator`。字段契约（JSON 交换格式）见 `01-pipeline-orchestrator/references/api-contracts.md`。

本技能**只产出「资产包清单 + 提示词/需求说明」，不直接生成图片或音频**。核心价值：**一致性 + 成本可控**——多视图不漂移（同一张脸/发型/服装），低权重资产不做全套（避免无效过剩）。

---

## 双轨制说明（大型商业制作必备）

本技能由两条线融合而成：
- **创作轨（出好图）**：`style-recipes` 词库 + `prompt-templates` 七段式，负责画面的电影级质感和美感。
- **工程轨（不出错）**：`make-spec` 身份拆分 + `asset-tiering` 状态隔离 + 参考图权限控制，负责跨集的一致性。

### 百集级大型制作三条底线（不崩秘籍）

如果你接的是几十/上百集的连续剧，单靠提示词文笔是不够的，必须守住三条防线：

1. **状态分离**：主角只做一次基础立绘（锁脸），后续所有受伤/换装全做变体图，严禁用一张图描述多套状态。
2. **工具兜底**：主角必须练专属 LoRA 锁脸；复杂动作（同框/打斗）必须 ControlNet 锁骨架；成图必须经局部重绘（Inpainting）修手修脸。
3. **克制文字**：AI 绝不直接生成可读文字，告示/牌匾/屏幕一律使用 `postproduction`（后期AE/PS贴字）。

## 核心心法（七条铁律，一句话版）

> 长解释已下放到各 references 对应章节，这里只留判据。产资产前先过这七条。

1. **先分级再产**：按「重要度 + 特写频率 + 换装 + 实体落地」判级（角色 L0~3 / 场景 S0~3 / 道具 P0~3 / 声音 M·F0~3），核心全量、氛围极简。
2. **形容词定方向 + 具体动作定执行**：氛围词给方向，紧跟「眼神/表情/姿态」具体动作锁执行（对照表见 `feature-catalog.md` 末尾）。
3. **先做视觉翻译决策**：内在性格词（心软/认死理/护短…）不长在五官上，不写进 prompt，性格留给表演。
4. **骨架模型无关，适配放最后一层**：核心描述不掺模型语法，交付前再套适配层；没说用哪个模型就问一句。**更进一步——「禁引擎参数」是解耦，不是限制**：前端七段式只写「画面长什么样」，把采样器/CFG/步数/画幅/尺寸/seed/负面词全部剥离到**后端控制台**（`05-data-center/engine-profiles/`），这样资产库才是「通用生产资料」，换任何新模型只改 profile、前端一个字不动。
5. **工程信息优先，禁止假拆解**：实体落地优先三视图/拆解/色卡/尺寸正确；假拆解降级为「逐组件单独成图」。
6. **风格不写一句话，按子档贴词栈**：选子档后整段贴入词栈（见 `style-recipes.md`）；真人写实尤其要带「去 AI 感」质感词 + 质感类负面词，否则出塑料脸。
7. **默认就是交付级，不需要切换模式**：skill 产出的提示词**默认按交付级质量下限走**——技术精度（prompt 质感词）统一高精度不降档、负面词必加、色温必写、4 选 1、验收 5 条 + 放大看细节。**资产数量（几张图/要不要色卡/要不要表情集）按分级走**，不因「交付级」就升档——L3 群演还是单张定妆照 + 文字色名。**质量下限拉高，资产深度按分级，两件事不冲突。**
8. **场景资产分三层画幅，禁 9:16 出 design plate**：场景按画幅角色分三类——design plate（16:9 横版母版）/ blocking ref（9:16 竖屏构图验证）/ 成片（9:16）。三者是三张图不是一张图三种裁法，详见 `scene-system.md`。

## 规则分级（每一条规则先标档，再谈执行）

> 借鉴 `short-drama-image-prompts` 的工程锁。本 skill 所有铁律/红线**不是平铺的**——每条规则分四档，违背后的处理力度不同。**别把「可覆盖的默认」和「绝不可破的结构红线」放在同一力度上。**

| 档位 | 含义 | 违背后的处理 |
|---|---|---|
| `structural_invariant` | **结构缺陷**（不产/阻断） | 直接阻断，打回，不产出 |
| `reviewed_invariant` | **需证据判断** | 审查者引用证据（字段/来源）判定 |
| `craft_default` | **常用做法**（可覆盖） | 可被创作者/视觉方向覆盖 |
| `taste_option` | **创作者选择** | 根本不是缺陷，不判 |

**现有铁律对标（给关键几条定档，其余按此逻辑类推）**：

| 铁律 | 档位 | 为什么 |
|---|---|---|
| 「一人一版不换脸」（三大铁律） | `structural_invariant` | 换脸=结构崩塌，直接阻断 |
| 「工程信息优先、禁止假拆解」 | `structural_invariant` | 假拆解=不可交付，阻断 |
| 「先分级再产」 | `reviewed_invariant` | 需对照镜头权重/特写证据判断 |
| 「默认纯白背景」 | `craft_default` | 是工程用途默认，可切 R2 浅灰影棚 |
| 「表情集 5 款还是 3 款」 | `taste_option` | 数量由复用目的定，不判缺陷 |

**用法**：产资产前，先问「这条规则是哪一档？」——`structural` 级（不换脸、禁假拆解）绝不妥协；`craft_default` 级（纯白底、默认 R1）可被用户一句「要活人感」覆盖；`taste_option` 级（表情几款、视图几个）随用途走，别当硬规矩卡死。

## 一句话模式（默认入口）

> 用户只说一句「我想要个甜美风的女生」「3D 清冷仙女」「赛博男主」这类轻输入时，**走一句话模式，不追问**。

**三步**：①解析 5 参数；②按默认值矩阵填；③路由到 A~J，产出「提示词 + 负面词 + 参数 + 5 个可替换槽位」。

### 解析表

| 参数 | 从哪抽 | 默认 |
|---|---|---|
| 对象 | 角色 / 场景 / 道具 / 声音 | 角色 |
| 媒材 | 2D / 3D / 真人（「动漫」→2D，「3D/CG/国漫」→3D，没说→真人） | 真人写实 |

### 输出格式（固定 6 块）
【判级】L2 单张定妆照（或对应级别 + 理由一句）
【解析】对象/媒材/风格/图种/补充 → 映射到子档 / 背景 / 色温
【中文提示词】完整 prompt（已过形容词拆动作 + 服装三要素）
【英文提示词】完整 prompt
【负面提示词】按风格选组（真人加质感类 / 3D 加压渲染成真人 / 可爱加压幼态）
【推荐参数】画幅 + 种子 + 模型专属参数（格式同 SKILL.md「输出格式」的推荐参数块）
【5 个可替换槽位】改这里就能变什么

### 质量下限（一句话也必须满足）

- [ ] 抽象风格词拆成「眼神 + 表情 + 姿态」具体动作
- [ ] 服装有「身份 + 性格 + 一个记忆点」，不能四件基础款平铺
- [ ] 负面词按风格选组
- [ ] 色温必须写
- [ ] 配饰 ≤2 件
- [ ] **3D 媒材统一高精度质感词**（不降档）

**不追问原则**：信息不全按默认值填，先产再让改。只有用户只说「来个角色」这种连性别都没有的，才问一句。

## 工作流决策树

```
用户请求
├─ 第一步（必做）：资产分级 —— 按「重要度 + 出镜/特写频率 + 是否换装 + 是否实体落地」判级
│   ├─ 角色 → L0/L1/L2/L3   场景 → S0/S1/S2/S3   道具 → P0/P1/P2/P3
│   └─ 声音/BGM → 配乐 M0~M3 / 音效 F0~F3（额外看情绪锚点+复用+原创成本）
├─ 有设定，要产出资产/提示词
│   ├─ 角色：单张定妆照 → A；多视图 → B；三视图/拆解 → F；材质/色卡/表情 → G
│   ├─ 场景：全景/多角度/拆解 → H    道具：三视图/色卡/使用态 → I
│   └─ 声音/BGM：主题动机/情绪/拟音 → J（产需求说明，不产音频）
├─ 给了真人照片要「换脸/真人原型」→ 分支 D（叠加型）
├─ 给了参考图要「反推提示词」→ 分支 E（叠加型）
└─ 图已出、要「定点改一处/局部重绘」→ `edit-and-revision.md`（有界编辑合同，四问缺一不可）
```

## 资产分级（四线速查）

**判级口诀**：特写多 + 换装 + 实体落地 → 升最高级；无特写 + 单造型 + 氛围性 → 降最低级；音频则「情绪锚点 + 主线 + 复用 → 原创，否则版权库复用」。

| 线 | 级别 | 判据 | 最高级（全量） | 最低级（极简） |
|---|---|---|---|---|
| 角色 L | L0~L3 | 镜头权重/特写/换装/实体落地 | L0 主角：全套资产包 | L3 群演：单张定妆照 |
| 场景 S | S0~S3 | 出镜时长/戏份权重/搭景 | S0 主场景：全景+多角度+拆解 | S3 空镜：单张氛围 |
| 道具 P | P0~P3 | 剧情推进/特写/实体制作 | P0 核心道具：三视图+色卡+拆解 | P3 杂物：文字 |
| 声音 M·F | M0~M3 / F0~F3 | 情绪锚点/主线/复用/原创成本 | M0 主题/F0 核心音效：原创 | M3 底噪/F3 环境声：复用 |

**共同红线**：工程信息优先 + 禁止假拆解 + 原创只给锚点余者复用 + 色卡按需（≤5 类）。完整定义、每级资产包明细见 `asset-tiering.md`。

> **多套造型乘数**：换装多套的角色，每套都出「立绘+配色卡」，三视图/拆解/材质样卡只投「主造型」或「实体落地套」——主造型优先级（实体落地套 > 戏份最多套 > 海报/主视觉套）见 `asset-tiering.md`。

## 目标模型适配（交付前最后一层）

**核心原则**：骨架模型无关，模型适配放最后一层——核心描述只写「要什么」（图种/人物/妆造/视图/背景/风格），不掺模型语法；交付前再按实际模型套适配层，没说用哪个就问一句。

> **引擎参数全部归「后端控制台」**：采样器 / CFG / 步数 / 画幅 / 尺寸 / seed / 负面词，这些**不是画面内容**，是「用什么引擎、什么参数出图」的能力。它们落在 `05-data-center/engine-profiles/`（`engines.json` + 每个引擎一个 `<engine_id>.json`），由脚本注入，**前端七段式绝不写**。换引擎只改 profile，前端一个字不动——这才是资产「通用生产资料」的本质。字段契约见 `api-contracts.md` 的 `EngineProfile` 对象。

| 模型 | 语言 | 参数/负面词 | 参考图入口 | 单图视图数上限 |
|---|---|---|---|---|
| **Midjourney** | 英文关键词堆叠 | `--ar`/`--style raw`/`--cref`/`--sref` 等；英文负面词 | 见下方 MJ 参考参数 | 一致性确认后再试 ≤8 |
| **SD / ComfyUI** | 英文 + negative | 英文负面词、采样参数（见下方 SD 参数表） | ControlNet / IPAdapter 锁脸 | 一致性确认后再试 ≤8 |
| **即梦** | 中文自然语言 | 中文负面词 | 平台「参考图」入口 | ≤4 |
| **通义万相** | 中文自然语言 | 中文负面词 | 平台「参考图」入口 | ≤4 |
| **文心一格** | 中文自然语言 | 中文负面词 | 平台「参考图」入口 | ≤4 |
| **豆包** | 中文自然语言 | 中文负面词 | 平台「参考图」入口 | ≤3 |
| **其他模型** | 按文档定 | 按文档定 | 按文档定 | 默认 ≤4 起步 |

**中文模型差异（F1，别笼统并列）**：

| 模型 | 强项 | 弱项 |
|---|---|---|
| 即梦 | 构图、多视图理解好 | 超精细材质 |
| 通义万相 | 写实、古风 | 多视图一致性 |
| 文心一格 | 国风、色彩 | 写实皮肤 |
| 豆包 | 自然语言长描述 | 精确构图（单图视图数降到 ≤3） |

**MJ 参考图参数（F3，按用途选，别只会用 `--iw`）**：

| 场景 | 参数 |
|---|---|
| 普通参考 | `--iw 2`（参考图影响拉满） |
| 锁角色脸（多视图/换脸） | `--cref <url> --cw 100`（脸权重 100） |
| 锁风格 | `--sref <url> --sw 100` |
| 锁角色 + 风格 | `--cref <url> --cw 100 --sref <url>` |

**SD 采样参数（F2，按用途搭配）**：

| 用途 | 采样器 | CFG | 步数 | 备注 |
|---|---|---|---|---|
| 真人写实 | DPM++ 2M Karras | 6~7 | 25~30 | 高 CFG 会塑料感 |
| 3D 渲染 | DPM++ SDE Karras | 7~8 | 25~30 | 细节多 |
| 2D 插画 | Euler a | 7~9 | 20~25 | 线条清晰 |
| 多视图 | DPM++ 2M Karras | 6~7 | 30 | 长步数保证一致性 |

**适配通用规则**：
1. **语言跟模型走**，不确定时中英双份都给。
2. **参数别硬塞**：`--ar`/`--iw`/`--cref`/`--style raw` 是 MJ 专属，其他模型不写它不认的参数（宁可少写，别写错）。
3. **负面词语言跟模型走**（英文模型英文、中文模型中文）。
4. **单图视图数可配置**：默认 ≤4 保守起步（豆包 ≤3），漂移再拆图；确认一致性强再放宽 ≤8。按实际模型版本调整，别当死值。

术语白话对照（中文模型需替换）：`flat studio lighting`→纯白背景光线均匀柔和无阴影；`full body/no cropping`→全身照脚部完整不裁切；`close full body shot`→近景全身人物占比大；`low/high angle shot`→仰拍/俯拍；`character design sheet`→角色设定图。

## 提示词骨架（「骨架 + 插槽」，不写死段数）

```
[1 图种] + [2 人物] + [3 妆造/服装] + [4 视图清单] + [5 排版] + [6 背景/光] + [7 风格/质感]
```

**段数按场景裁剪**：单张定妆照用 3~5 段（图种+人物+妆造+背景光+风格）；多视图/模型表才扩到 6~8 段补「视图清单+排版」。每段是「插槽」，有内容才填、没就删。第 [2 人物] 段「按需填满不硬凑」：主角写全、群演只挑 2~3 个锁脸项。完整模板、中英双版、负面词清单、翻车点对照见 `prompt-templates.md`。

## 输出格式（每项资产固定四段，中英双份）

```
【中文提示词】<完整中文 prompt>
【英文提示词】<完整英文 prompt>（喂 H3/MJ/SD 更稳，优先用这版）
【负面提示词】<规避内容，中英皆可，英文优先>
【推荐参数】
  - 画幅：9:16 竖版 / 16:9 横版（按图种）；种子：多视图整图固定一个 seed
  - MJ：`--ar 9:16/16:9` + `--style raw` + 锁脸 `--cref <url> --cw 100`（或参考 `--iw 2`）
  - SD：按用途搭配采样器+CFG（见「目标模型适配」SD 参数表）+ 参考图 ControlNet/IPAdapter
  - 中文友好模型：**不写参数用平台默认**，负面词用中文
  - 不确定模型：只写通用项（画幅+风格+同一种子）
```

> **前后端解耦后的产出口径**：「中文提示词 / 英文提示词」是**前端画面描述**（模型无关）；「负面提示词 / 推荐参数」属于**后端引擎能力**，实际批量出图时应从 `05-data-center/engine-profiles/` 注入，而不是手工写死在每张资产上。单人/单张交付时两者合并写给人看没问题，但落到数据中台 + 脚本批量出图时，前端只存画面描述、后端只存引擎参数。

产出资产包时：先给「分级 + 资产清单」再逐项给提示词；实体落地类（三视图/拆解/色卡）必须标色卡与工程信息。

## 角色线（分支 A~G）

> 人物是主体线：成熟度最高、用得最多。A~C 是图种分支，D/E 是叠加型，F 是实体落地，G 是辅助资产。

## 分支 A：单张定妆照

1. 套 `prompt-templates.md` 模板一。画幅按用户指定（默认 9:16 竖版），全景从头到脚完整入画。
2. 角度默认「正面」或「正侧面 45°」；背景**默认纯白（R1 干净影棚）**；切 R2 呼吸感时改浅灰影棚（见 `style-recipes.md` 子档背景光约束）。纯白不是唯一，是工程用途的默认；要活人感/展示时用 R2 浅灰底。
3. 风格三选一（2D/3D/真人写实），默认真人写实 **R1 干净影棚**（要活人感切 R2，见 `style-recipes.md`）——**按子档贴词栈**。**3D 媒材统一高精度质感词**（高精度 CG 质感/真实材质反射/电影级光影层次/8K），不降档；风格化需求（BJD/Q版）走高精度渲染但词栈不加写实词（见 `style-recipes.md` 技术精度节）。
4. 全身景必写「从头到脚完整入画、脚底和鞋完整、脚下留地面、绝不裁脚、人物占画面 70%」。注意：中文可写「70%」，英文改用 `minimal headroom and legroom`（见 `prompt-templates.md` B1 说明——数字会被模型误解成构图框）。
5. **参考图优先原则**（有参考图时必读，见下方「参考图优先」铁律）：只写「保留什么/改什么/扩展什么」，不重复描述参考图已有的内容。
6. 输出中英双份 + negative + 参数。

### A-双人/多人同框变体

> 真实项目经常有「男主女主同框」需求，单角色 prompt 写法不适用。多角色同框的核心是「分段描述 + 主次权重」。

**写法要点**：

1. **分段描述**：每个角色一段，先写主角色，再写次角色。不要混在一起写。
2. **构图**：左右站位 / 前后景 / 互动姿态（对视 / 并肩 / 一前一后）。
3. **身高差**：写相对比例（`noticeably shorter, head reaches his shoulder`），不写绝对数字。
4. **主次权重**：MJ 用 `--iw` 调参考图权重；SD 用 regional prompt（区域提示词）。
5. **一致性**：两张参考图分别对应两个角色，prompt 里分段锚定。

**prompt 结构**：

> 双人定妆照，[构图：左右站位/前后景]，[画幅]。[角色 A 段：完整描述 + 位置「画面左侧」]。[角色 B 段：完整描述 + 位置「画面右侧」]。[身高差/互动描述]。[背景/光]。[风格]。

**注意**：多角色同框的一致性比单人难一个量级——**先用单角色定妆照各自锁定，再做同框**，不要直接双人 prompt 从零出图。

## 参考图优先原则（铁律，分支 A/D 通用）

一张参考图的权重 > 1000 字描述。有参考图时，提示词的作用不是「从头描述一遍」，而是：

- **描述要保留什么**：「保留参考图的脸型、五官比例、发型走向」
- **描述要改什么**：「服装改为深色短打甲衣、去掉眼镜、眼神改为冷厉」
- **描述要扩展什么**：「扩展为多视图」

**不要重复描述参考图已有的内容**——重复 = 浪费 token + 干扰参考图锚定。提示词 > 1000 字但仍漂移时，第一反应是「加/换参考图」，不是继续加词。

## 分支 B：多视图角色设定图

> **前置**：先确认定妆照「锁定成功」（验收 5 条：脸清晰无畸变、发型走向明确、服装结构可辨、背景纯白无阴影、双眼睁开视线明确），见 `view-spec.md` 文首。不过就先修定妆照。

1. **开头默认「参考定妆照」生成**：第一句写「用参考图片生成人物多视图，保持绝对一致——同一张脸/发型/服装/配色/五官比例，只扩展视角，不换脸/不改妆造/不漂移」。仅当用户明确「没定妆照/纯文字」才退回纯文字版（`prompt-templates.md` 模板二）。
2. **先看模型再定视图数**：默认 ≤4 保守起步，确认一致性强再放宽 ≤8，超了就拆多张（面部四视图一张、身体四视图一张、姿势/特写再分）。弱一致性模型强烈建议拆图，别一张塞 12~15 视图——这是跑偏最大原因。
3. 套模板二，视图清单与排版见 `view-spec.md`。画幅 16:9 横版、背景纯白。
4. 硬约束写进 prompt：绝对一致、无重叠遮挡、无明显分割线、身体视图不要头部。
5. 生成方式二选一（见 `view-spec.md`）：方案 A 单图（视图数在单图上限内）；方案 B 分块生成（弱一致性模型默认，每块以同一张定妆照为参考图）。翻车走三级降级路径（脸漂移→先强化锚定/减视图数；漏视图→减视图/拆图；乱序→写死顺序；网格线→写「不画网格线/框线」；都失效才拼接）。

## 分支 C：角色模型表 / 技术设定图

- 与分支 B 区别：纯白背景、无投影阴影、无文字标签、纯平光、身体视图颈部以下裁切（不要头部）。
- 布局左右两列分区（左两行=面部四视图+身体四视图，右两行=姿势+特写），视图间靠留白、不画网格线/框线。
- 拆图规则同分支 B（模型表视图数多，几乎必然拆图）。见 `view-spec.md`「模型表专用约束」。

## 分支 D：换脸 / 真人原型（叠加型，可叠加 A/B/C/F）

1. 用 ViewImage 读真人照片五官特征。
2. **先问用户**：眼镜去留、气质是否保留（真人照片常带眼镜/特定表情，与角色设定可能冲突）。
3. prompt 写「严格保留五官特征，去掉眼镜/眼神改为××」。
4. 注明「参考图 = <照片>」，提示用户把照片作为参考图上传。

## 分支 E：反推提示词（叠加型）

1. 用 ViewImage 读参考图，按骨架逐段还原。
2. 区分「参考图本身」和「图里内容」（如手机拍屏，反推的是屏内图而非拍屏动作）。
3. 输出中英双份 + negative。反推后问用户是否要调整重出。

## 分支 F：三视图 / 服装爆炸拆解图（实体落地：cos/打版/3D）

1. **三视图**（正/侧/背）：正交、无透视、纯白底、平光、无文字、等大等距不重叠靠留白分隔、标色卡。
2. **简化拆解图**：只拆「独立可拆卸组件」（发冠组/外袍/内衬/束腰/腰饰/披帛/下裙），不拆贴身小件；每组件单独一图、标装配关系（谁在谁外/谁压谁）。
3. **禁止假拆解**：AI 爆炸图常是「炸开碎片」。真拆解 = 组件独立成立 + 层叠清晰 + 对应三视图。**判定法**：每个组件单独裁出来看是否完整部件、能否看出层叠关系——只是「一片布/碎片」即假拆解，降级「逐组件单独成图」（见 `asset-tiering.md`）。
4. 打版/建模优先 3D 渲染（PBR 正交）或 2D 线稿，不选真人写实。输出附色卡。

## 分支 G：辅助资产（材质样卡/配色卡/表情集/道具卡）

按分级按需产出（L0 全量、L1 部分、L2/L3 省略，见 `asset-tiering.md`）：
1. **材质样卡** ≤5 类够用；**配色卡**可与三视图/立绘共用，不单独出图。
2. **表情集**：L0 出 5 款、L1 出 3 款。**情绪词也拆具体动作**（「冷厉」→眉压低+眼微眯+嘴角抿紧），每款写「哪个部位+什么动作」，不是写情绪名词。**要做「呼吸感」表情集时，负面词追加 `prompt-templates.md` 的「真人写实·质感类」组。** 高风险情绪词（如「杀意」）投喂敏感平台时改安全替代（见 `feature-catalog.md` D2）。
3. **道具卡**：正面+侧面、纯白底、平光、标尺寸/材质/配色。

## 分支 I：道具设定（三视图/材质色卡/使用态）

## 分支 J：声音 / BGM（需求说明，不产音频）

1. **M0 主题曲**：主题动机描述（情绪/速度/调式/配器）+ 场景锚点 + 参考曲风，范例见 `examples.md` 案例七。

3. **F0 核心音效**：触发场景 + 声音质感（拟音材料方向）+ 世界观锚点。
4. **F2/F3**：版权库检索关键词或素材清单。

## 执行层速查（关键纪律浓缩，替代长文）

> 与核心心法重复的内容已合并。负面词语言跟模型走（见「目标模型适配」）。

**气质与人物**：形容词必配「眼神/表情/姿态」具体动作；内在性格词不写进 prompt；人物描写具体（主角写全、群演挑 2~3 项）；胡子/眼镜精确（「八字胡+山羊胡」≠「络腮胡」，去眼镜要显式写）。

**结构与一致性**：图级硬约束放开头、「绝对一致」置最前；先约束再内容（「身体四视图：均颈部以下、不要头部。正面、45°、90°、背面」）；排版写死（左右两列、不重叠、留白分隔、不画线框）；锁视线+锁眼睛状态+锁发型（三要素+鬓角走向+刘海分布）；同一种子 seed 不刷新。

**构图与光影**：全身图必写「脚不裁切+占画面 70%」；背景纯白平光砍侧逆光/轮廓光；仰俯视写「机位+朝向+范围」三要素；细节特写写死部位边界（「只拍双手、手掌手背、居中占满整格」）；特写按需 0~3 个。

**风格与工程**：风格三选一不混用；先分级再产；工程信息优先+禁假拆解；段数按场景裁剪；只输出提示词不调图像生成工具。**3D 统一高精度质感词（不降档）**——高精度 CG 质感 + 真实材质反射 + 电影级光影层次 + 8K；但技术精度和风格词栈是两层：BJD 走高精度渲染不加写实词，2D 走高完成度不加 3D 渲染词（见 `style-recipes.md` 技术精度节）。

## 批量出图策略（C1：一次不出，4 选 1）

> 「出好图」的基本盘是**批量 + 选片**，不是「一次出就该完美」。反复改 prompt 而不重 roll，是低效根因。

**出图数量基线**：

| 图种 | 每次出几张 | 选几张 |
|---|---|---|
| 单张定妆照 | 4 张 | 选 1 锁定 |
| 多视图（单块：面部/身体四视图） | 4 张 | 选 1 |
| 表情集（每款） | 2~4 张 | 选 1 |
| 特写（每个） | 2 张 | 选 1 |

**选片标准（按优先级，从上到下）**：

1. **脸清晰无畸变**（第一优先，脸错了其他都白搭）
2. **结构准确**（服装、发型、配件无错位）
3. **光影符合**（纯白底没阴影、平光没硬光）
4. **构图符合**（视图位置、占比、裁切对）
5. **细节质感**（纹理、皮肤、材质）

**关键**：不要用「改 prompt」解决「随机出图」问题——先 4 选 1，不行再改 prompt。改 prompt 前先确认 seed 没漂。

## 极速模式（C3：时间紧时的 MVP 路径）

> **触发**：L3 群演、L2 功能配角、或整体预算紧时（如「1 天出 20 个群演」）。别卡在「该不该写多视图」上。**极速模式只用于 L3 群演和内部草稿，不用于交付级资产——交付级走默认基线（核心心法第 7 条）。**

流程：

1. **跳过多视图、跳过负面词精修、跳过色卡**。
2. 单张定妆照 + 单条提示词（3 段：人物 + 妆造 + 背景/风格）。
3. 同 prompt 换 seed 出 8 张，人工选 1 张。
4. 不同群演之间只改脸型/发型/服装色（同一模板复用）。
5. 每张控制在 2 分钟内。

**验收标准放宽**：脸清晰、不畸形、无换脸即可；不强求「活人感」「材质质感」。

## 术语表（E1：统一用词）

同一概念固定用词，别混：

- **纯白背景 / 纯白底**（可互换，统一指 #FFFFFF 纯色背景；「纯白底」更简洁、「纯白背景」更正式，不强求统一）
- **锚定**（动词用「锚定」，不用「锚点」作动词；「锚点」只作名词，如「情绪锚点」「世界观锚点」）
- **主造型**（指代造型概念，不用「主立绘」）
- **视图**（不用「子图/格子」）
- **定妆照**（单张锁定形象；多视图是「多视图设定图」）
