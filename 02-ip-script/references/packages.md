# 门禁字段清单（阶段 0 评估报告 + 三个 package）

> 门禁统一原则：**package 必填字段齐全才放行到下一阶段**。以下清单就是门禁的校验依据。

## 阶段 0 评估报告（ip-eval 产出，进阶段 A 前的门禁）

> 阶段 0 是「批量初筛、决定要不要进 A」的关卡，其产出同样要被门禁卡住——评估结论不完整，不进阶段 A。

- [ ] 赛道分流结论 + 语速标准（中文字/秒 vs 英文词/秒 vs 解说 4.5~6.5 字/秒）
- [ ] 题材热度 / 改编适配度 / 平台匹配 / 商业潜力（逐项打点，缺一不可）
- [ ] 投资额分级预判（80万+ / 30–80万 / <30万）
- [ ] 数据画像（追读率 / 付费转化 / 完读率）
- [ ] 「通过 / 不通过」结论（不通过 → 换下一部 IP，不救稿）

## adaptation-package（阶段 A 产出）

- [ ] 赛道分流结论 + 语速标准
- [ ] 开发圣经（bible：世界观 / 人物定型 / 台词风格 / 平台节奏矩阵 / **底牌分层+揭示节奏表**）
- [ ] 爽点曲线判定（开头即爆 / 中后期才爆）+ 情绪 12 节拍曲线
- [ ] 锚点索引（保留名场面 / 金句定位表）
- [ ] 分集规划表（含**每集揭示进度标注**：本集落在哪层揭示点之前/之后）
- [ ] 逐章改编稿（带来源标记 / 台词类型 / 情绪光影 / 动作链）
- [ ] 来源等级表（每处内容 直用 / 改写 / 新增 标记）
- [ ] 台词七维诊断结论
- [ ] highlights（可直用高光片段）
- [ ] payoffs（爽点 payoff 清单）
- [ ] 分级定档结论（投资额三档 + 备案路径 + AI 标识方案）
- [ ] 数据画像（追读率 / 付费转化 / 完读率）

## pilot-package（阶段 B 产出）

- [ ] 先导片剧本（完整）
- [ ] 钩子清单（每个钩子来源：已验证 / 预测）
- [ ] **剧透审查结论**（逐条核对「留白 vs 剧透自检清单」，确认未提前揭底牌；并对照开发圣经「底牌分层+揭示节奏表」确认各层底牌仍在留白中）
- [ ] 分级定档一致性声明（与 A 阶段一致）

> 说明：先导片是「独立交付物」，不产出定妆单/资产清单/简介单这三件——它们是「全剧定稿后」的制作层交接物，统一在阶段 C 产出（见 series-package）。先导片阶段的「出场角色/道具」一致性，由「钩子纪律」里的「次要势力简化」兜底，不单独建清单。

## series-package（阶段 C 产出）

- [ ] 分集剧本（全集，每集头部带「揭示边界 / 禁词 / 时间轴」注释）
- [ ] **完整剧本（全剧连体整本，C6 合成，供送审/交付）**
- [ ] 分集大纲（回溯 A4 分季切分 + 每集揭示进度）
- [ ] 平台级分级结论（针对目标平台）
- [ ] 合规精审结论
- [ ] 简介单 / 人物定妆单

> **资产清单表不在 series-package 里**——它由分镜环节（`storyboard-table`）在分镜表定稿后统计产出，作为「分镜后交接物」，不进剧本层的 package。
